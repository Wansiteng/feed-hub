OpenAI 的 Dot agent：能帮你订晚餐的企业软件

The Verge · AI · 评分 7/10：OpenAI 新 agent 平台发布，架构与能力值得关注
原标题：OpenAI’s Dot agent is enterprise software that can also order your dinner

要点

  • OpenAI 推出 agent 平台 Dots，优先面向每月 100 美元的 Pro 等最高档账户
  • Dots 可访问 Blender、GIMP 等应用，也能通过桌面版 ChatGPT 接入用户电脑
  • 测试中 Dots 多次卡在人机验证，订餐、宜家登录等任务失败

这是个上周才出现的新鲜事：OpenAI 的新 agent 平台名叫 Dots，里面全是些可爱的小家伙，能替你办事。

但与极其亲民的 Meta Muse 不同，Dots 用起来很像一款碰巧能帮你点墨西哥卷饼的办公软件——重点在办公。

OpenAI 本周早些时候发布了 Dots。和 Muse 一样，Dots 有着圆滚滚的拟人化形象和可自定义的名字。OpenAI 表示，未来你可以拥有多个 Dots，但目前只能有一个。我给我的取名叫 Dotty McDotface。

界面看起来和 Muse 类似：你在一个窗口里和 agent 聊天，在另一个窗口里看它在虚拟机上点来点去地干活。但 Dots 不太像私人购物助理，尽管它们能帮你买东西。它们更像同事：一款能调用其他软件的商业软件。你的 Dot 的虚拟机开箱就能访问 Blender 和 GIMP 这类应用。你还可以通过桌面版 ChatGPT 应用让它访问你自己的电脑，需要边想边说时也能直接呼叫你的 Dot。OpenAI 首先向最高档账户的用户提供 Dots，包括我为了测试而报销的每月 100 美元的 Pro 账户。Muse 及其热门竞争对手 Instinct 都是免费的——至少现在是，至少要等 Meta 把它做起来，然后大概会开始用它给你推广告之类的。但 OpenAI 这种限制开放的推出方式，很能说明这款产品是给谁用的，尽管它有着可爱的形象。

我一直在用日常个人任务测试其他 AI agent——结果喜忧参半——我很好奇 OpenAI 的机器人会表现如何。尽管它更有企业范儿，但 OpenAI 声称 Dots 凭借其云端电脑和对各类应用的访问权限“几乎什么都能做”，所以我就用一些更普通的场景试了试。

首先，我让 Dot 试着为我家新办的一家网络服务商预约安装时间（听到了吗，Comcast？你被盯上了）。它几乎办成了，甚至在我已批量删除的邮件里找到了一张 100 美元的促销折扣，但卡在了“人机验证”上。这对一个机器人来说是个麻烦。“这个验证需要持续按住鼠标，而我的浏览器控制不支持这个操作，”它说。“请在这里打开我的浏览器，按住‘Press & Hold’直到完成，然后告诉我，我会继续处理安装日期。”我照做了，但这感觉有点像便利店外的青少年让我帮他们买几瓶葡萄酒冰饮。

截图：The Verge / OpenAI

靠我人类按住按钮的能力，Dot 一路走到了结账页面，然后它让我输入银行账户信息。原来它没有像 Muse 那样流畅的 Stripe 集成，无法保存你的信用卡信息并用虚拟卡结账。而且无论如何，这家新服务商需要我的银行账户才能每月账单减免 5 美元。Dot 停下来让我在虚拟浏览器里输入数字；我不太信任它，不敢输入我的支票账户号码，决定干脆在自己的电脑上全部自己来。这开局可算不上惊艳。

我还给 Dot 布置了其他几项个人任务，结果好坏参半。它找不到我一直想尝试的一家共享办公空间的免费参观和入场选项，反而提出帮我注册一张 35 美元的日票。我让同样在测试的 Instinct 的 agent 去找试用选项；它找到了，并在几分钟内安排好了预约。“你为什么漏掉了这个选项？”事后我在电话里质问 Dot。“我草率地得出了错误结论，”它说。我挂断了电话。

截图：The Verge / OpenAI

后来，我让它去我的宜家账户里查一些关于我买的一个吊篮的信息。它报告说无法登录我的宜家账户，因为卡在了一个循环的安全检查里。在互联网的其他地方，附近的照烧店不让 Dot 进入其订餐页面。Dot 的某些特征似乎让它比 Muse 或 Instinct 更频繁地被安全检查绊住；Dot 提供了一个链接，指向 OpenAI 关于网站屏蔽其云浏览器流量的页面作为解释。不管原因是什么，它比其他 AI agent 需要更多手动输入和浏览器接管，可能是因为它不是专门为订购照烧或处理你的宜家退货而打造的。

当我让 Dot 访问完全在我控制之下的东西——我的个人网站时，我才真正看到它大显身手。这个网站过时得令人尴尬，我让 Dot 整合出一个更简洁的新设计。它做到了，当我坐下来打出下一版想要的一些修改时，我想：“管他呢。我直接给它打个电话。”我在 10 分钟里逐节敲定了想要的修改，然后走开去洗碗，接着收到一条提示，说下一个迭代版本已经准备好供我审阅。不完美，但更好了。AI 再次证明，当你给它一个大型数据集（我絮叨了 10 分钟）时，它最能帮上忙，能把它变成有用的东西。我又进行了几轮迭代，在电脑上的浏览器窗口里和 Dot 聊天，同时在家里四处收拾 Brio 火车轨道和毛绒玩具时用手机应用上的语音转文字。

Dot 的某些特征似乎让它比 Muse 或 Instinct 更频繁地被安全检查绊住

当我让 Dot 访问我的电脑后，它就合理多了。在那里，我给了它两项任务：把我桌面上几个关于我参与的一个电视热门节目的视频文件整合成一个尺寸适合社交媒体的片段，以及部署我们在原型中敲定的个人网站修改。我不得不给它多得惊人的权限，但它成功了。我看着它在网站后台点击操作，一块一块地重建原型。我离开电脑，在手机上的 ChatGPT 应用里收到更新——整合好的视频片段已经就绪，我一边喝咖啡一边审阅了它。这是我一生中最有硅谷感觉的时刻。

我绝对可以自己想办法把那些片段拼在一起。事实上，我第一次就是这么做的，但看起来粗糙，而且太大，无法上传到任何社交媒体网站。Dot 做得要好得多，我几分钟内就有了一个可以分享的片段。它也处理了网站更新。新设计很基础，但比我昨天之前一直用的那个复杂、过时的版本强太多了。得给 Dotty McDotface 点个赞。

截图：The Verge / OpenAI

当你把 Dot 理解为“面向普通人的 Codex”并这样使用时，它就合理多了——一个可爱的小团块，能在你忙别的事情时帮你处理业务中的某些部分。像 Muse 这类更偏个人化的 AI agent 感觉像是被吹上天的自动填充和一个万能网购购物车，而 Dot 则像是未来工作方式的先兆。

或者说，是某一种未来工作方式。想必，既然你是预先付费的，它就不会像 Muse 和 Instinct 最终那样受到变现压力，这对企业软件来说是合理的。没人希望工作时被 AI 唠叨。也就是说，前提是你做的工作恰好是 AI 能帮上忙的那类，而且你信任 OpenAI 来做这件事。这可是很大的前提！

它帮我处理了一些任务，说实话，那些事我本来根本就不会去做。这确实挺方便的。但我不觉得它方便到值每月 100 美元，至少在我这一行是这样。我能看出它对像我们的朋友 Casey Newton 那样的人会有用得多，他正忙于创办一家新公司。

而且在帮我登录 Uber Eats 账号之后，它最后还真帮我点到了照烧饭。
