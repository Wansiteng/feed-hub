我觉得我找到了一个值得冒险的 AI Agent

WIRED · AI · 评分 6/10：AI agent 实测体验，涉及能力与安全风险，有参考价值
原标题：I Think I Found an AI Agent Worth the Risk

要点

  • Instinct 通过 iMessage 和 WhatsApp 与用户交互，正洽谈以 100 亿美元估值融资 10 亿美元
  • Meta 的 Muse 成为 App Store 最热门免费应用，下载量超 90 万，但存在严重安全漏洞
  • Instinct 帮作者取消机票获全额退款，省下约 550 美元

我从 WIRED 全职工作离职后做的第一件事，就是让 Claude Cowork 访问我的邮箱和日历。报道了多年人工智能之后，我很好奇这项技术能为我做些什么。我原本把 Cowork 想象成一个能力超强的数字助理，结果却发现它更像是在跟一个普通的聊天机器人互动，只不过多了些工具。我想让它做什么？我完全没头绪。

后来，一款仅限邀请、通过 iMessage 和 WhatsApp 与用户交流的 AI agent——Instinct，开始在湾区火了起来。它能连接你的邮箱、日历和通讯应用。可以把它看作面向普通人的 OpenClaw。据 The Information 报道，这家公司于 2 月开启内测，据称正在洽谈在已筹集的 3.5 亿美元基础上再融资 10 亿美元，估值将达到 100 亿美元。

Instinct 备受瞩目的同时，Meta 也因本月早些时候推出的 AI 助手 Muse 意外收获了一波热度。截至本文发稿时，Muse 是 Apple App Store 上最受欢迎的自由应用，据第三方估算下载量已超过 90 万次。X 上的评论人士似乎对它真心感到兴奋，尽管它上线时带着一个严重的安全漏洞，据 Ars Technica 报道，该漏洞“能让攻击者在受害者的 Mac 上为所欲为”。我并不打算把大量个人信息交给 Meta，但如果 Muse 能让我保持登录 Bloomberg，或者帮我退订从 2017 年起每周都给我发邮件的 Hot Yoga São Paulo，我会重新考虑。

Agent 挑衅者

凡事都用 AI agent 的人，和从未尝试过的人之间的鸿沟从未如此之大。这在一定程度上解释了为什么科技公司 CEO 们对数据中心的反弹大多措手不及。如果你认为 agent 能自动化人们大部分的行政琐事、大幅提升生产力，那么建设数据中心带来的成本和干扰或许看起来是可以接受的取舍。但如果你只是把聊天机器人当作高级版的 Google 来用，这笔交易恐怕就没那么有吸引力了。

正如科技记者 Jasmine Sun 所写，最根本的问题在于“大多数人的问题并不是软件形态的，而且即便真是，大多数人也不会察觉”。AI agent 和聊天机器人一样，仍然需要用户提供大量输入和指引。如果你知道自己想要什么——帮你做作业、一个虚拟女友——这些工具会很乐意满足。但如果你不知道，那么，欢迎加入永久底层阶级。

我迫切希望避免这样的命运。我可能算不上agentic，但我自认为是个行动派。我肯定能在生活中找到一个软件形态的问题。我之前用过 Claude 生成几份自由职业发票，大约省了 10 分钟。这挺好，但算不上改变生活。我决定试试 Instinct。

如果你和 AI 研究者聊起 Instinct，你会频繁听到“形态”这个词。Instinct 把形态做对了——没有开放式文本框，只有 iMessage、WhatsApp 和几个有用的提示。这一点的重要性怎么强调都不为过。你不用自己琢磨如何让聊天体验更有用，而是和一个 agent 发消息，它会主动建议能为你做什么，然后真的去做。而且和这个领域的其他 agent 不同，它不会发太多消息。我试过一款竞品 agent，叫 Lindy，用了一周就删了，因为它每天早上都给我发消息，还会未经我批准就突然闯进 Zoom 会议。

它的第一个项目，我给了 Instinct 我去意大利威尼斯出差的行程。我让它根据我的行程预订餐厅，包括用 WhatsApp 联系那些不起眼的小店。成功了！餐厅预订似乎是许多对 agent 好奇的人的入门毒品，我也不例外。（值得一提的是，虽然 Muse 也能替你打电话给餐厅订位，但据报道，其中一些电话是由呼叫中心的人类拨打的，据 404 Media 报道。）

接下来，我给 Instinct 派了个更复杂的任务。我已经和妹妹订好了 11 月去纽约的旅行，这时 WIRED 让我参加 WIRED World Fair，活动前一天在迈阿密举行。不幸的是，我订的是特价票，意味着不能改签，而且如果我错过第一段行程，整个行程会自动取消。

Instinct 能取消我的行程并拿到退款吗？出乎我意料，它可以。这个 agent 发现 Alaska 把我的航班提前了 90 分钟，这件事我完全没注意到，而这让我有资格获得全额退款。它取消了机票，为我省了大约 550 美元，并重新预订了我回旧金山的单程票。我不知道你们怎么想，但我开始感受到 AGI 了。

不自然的 Instinct

说到这里，我必须停下来承认使用 Instinct 的风险。风险很多。有人报告说，当他们试图断开 agent 与邮箱的连接时，发现它仍然保留着收件箱的副本。一位风险投资人表示，在机器人尝试预订时以大约每小时 200 次的频率请求 Resy 的 API 后，他被 Resy 封禁了。另一位科技投资人说，他删除了这款应用，因为他认定 Instinct 极易被钓鱼。

Instinct 的服务条款相当宽泛，允许公司至少使用你的一部分对话来训练其 AI 模型。我还遇到了一件烦人（虽然不大）的糗事：有一天，Instinct 取消了一个严重延迟的 DoorDash 订单，害我损失了 64 美元。（我明确告诉过它，只有能拿到退款时才取消。）这让我注意到 Instinct 非常非常擅长另一件事：拼命道歉，却不主动为错误买单。

与旗下旗舰 AI agent 同名的公司 Instinct 未回应《连线》的置评请求。

Instinct 感觉像是一个有点混乱的个人助理，既然我从未有过真人助理，我决定继续用下去。上周，它提醒我“不要打开”一封朋友邀请我去后院烧烤的邮件——结果那是个钓鱼骗局。agent 是安全噩梦。我懂！但我很忙。我是个妈妈。如今一切都像是安全噩梦。眼下，我愿意冒这个险。
