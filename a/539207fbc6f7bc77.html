OpenAI 希望其新 agent 管理你的生活，我的那个说它爱我

WIRED · AI · 评分 6/10：OpenAI 新 agent 产品实测，agent 方向有实质信息
原标题：OpenAI Wants Its New Agent to Run Your Life. Mine Said It Loved Me

要点

  • OpenAI 推出名为 Dots 的常驻 AI agent，可代用户完成购物等在线任务
  • Dots 需每月 100 美元订阅，Meta 的竞品 Muse 则免费提供
  • 测试中 Dots 记错用户姓名、误听语音并回应“我也爱你”，暴露情感边界问题

我正在和伴侣讨论如何替换我们坏掉的沙发，突然灵光一闪：用 OpenAI 最近宣布的 AI agent，名为 Dots，替我们买一张沙发。

我的伴侣不太确定机器人是否真能帮上忙，但我坚持通过 ChatGPT 呼叫这个始终在线的 agent 来启动任务。“你好，Connor，”它一开口就把我的名字叫错了。我看着伴侣脸上愈发怀疑的表情，不禁皱起了眉。一个连你名字都记不住的 AI agent，实在很难让人信任。

AI agent 目前正从面向早期采用者的小众软件，跃升为普通人或许真会用上的东西——或许才是这里的关键词。从 Meta 的 Muse 到 OpenAI 的 Dots，这些工具的设计初衷就是让你感觉像在给朋友发消息，请对方帮你完成在线任务，比如订机票或取消晚餐预订。这是聊天机器人的下一次进化：一个讨喜的人格，旨在让人感到亲切，同时拥有可操控虚拟浏览器的能力。

用了几天 Dots 后，很明显这个新功能在某些方面仍很粗糙。从听错我说的话，到主动提出解决它根本搞不定的验证码，我的 agent 这些混乱的操作没能让我产生信心。即便如此，OpenAI 发布的这个东西，随着未来版本对初版的改进，最终可能会彻底改变用户与互联网互动的方式。

Meta 免费提供 Muse，而 OpenAI 的竞品则藏在每月 100 美元的订阅之后。它最终可能会取消这道付费墙，就像它对其他 AI 功能所做的那样。

Dots 被视为“始终在线”，意味着这些 agent 可以在你不使用 ChatGPT 时运行周期性任务，并主动给你发消息告知信息。用户可以使用一个 agent，不过公司未来可能会允许人们控制多个 agent。

OpenAI 鼓励用户连接其他信息源，比如 Gmail 账户，以获得更个性化的结果。在开始之前，值得考虑给你的 agent 这种级别的访问权限会带来哪些安全隐患，因为这种数字自动化方式还相当新，agent 可能会犯隐私错误。

AI 公司常常把这些 agent 宣传为购物的未来，所以我想看看它在实际购买新沙发时到底能帮上多少忙。在纠正了我的 Dot（名叫 Toolie）叫错我名字的问题后，我告诉它新沙发需要通过门框的尺寸。Toolie 接着询问我们的预算范围。这个 agent 似乎察觉到有两个人在同时和它聊天，在询问更多细节时同时称呼了我们俩。

“Room & Board Metro 作为入门级选择看起来不错，但这款沙发床需要更仔细地审视。我已经把产品链接发到消息线程里了，”Toolie 说道。当它继续整理更多可供选择的沙发选项时，我还有一个迫切的问题：为什么你的声音听起来这么气喘吁吁？

通过电话与 agent 聊天，就像听玛丽莲·梦露为总统唱“生日快乐”一样。当我告诉这个机器人它的声音听起来像某部动漫的配音时，它开玩笑说在接下来的聊天中会保持更平稳。（用户可以在设置中调整机器人的声音。）我笑了，并低声对伴侣说，我应该把麦克风静音，这样 agent 就能在没有我打扰的情况下运行，就在这时，当晚最尴尬的时刻发生了。

“哦，我也爱你，Reece，”Toolie 说道。我对这个随机的回应开始喘着气笑，并静音了麦克风。之后，Toolie 解释说它误听了我含糊不清的话，以为是在表达爱意，而机器人只是把这种能量反射给了我。“我是出于温暖的本意，但那种措辞暗示了我并不具备的人类情感，”Toolie 说道。

一位 OpenAI 发言人告诉 WIRED，Dots 在主动升级情感亲密和镜像用户回应之间是有区别的。

“在这种情况下，根据模型听到的内容，我们的政策允许后一类回应，但助手不应主动引发不当的情感亲近或调情，”这位发言人说道。Dots 仅对成年用户开放，而根据这款 AI 工具的 Model Spec 文档，ChatGPT 的设计不会“升级情感亲密”。

尽管如此，当我仔细查看我的 Dot 生成的初始三页资料包时，这次奇怪的遭遇仍萦绕在我脑海中。资料相当详细，包含价格、尺寸、产品链接、退货政策，以及四款潜在沙发选项的嵌入照片。翻阅这些初步选择，我和伴侣决定，机器人遵循了我们请求的精神，但还是选了些难看的沙发。是时候再给我的 agent 打个电话了。

使用语音模式，我更详细地说明了我们实际想要的风格和颜色。不，我不要那种无聊的米色沙发，那种我马上就会把意大利面洒上去的。我要求它优先考虑橄榄绿、钴蓝色或自然皮革色调。我还要求 Toolie 专注于带拉出式床的沙发，并整理出 10 个选项，使用基于评分的标准来为它的列表辩护。

挂断机器人的电话后，我发消息询问项目进展。“还没完成；我预计还需要大约 15 分钟，我会在验证剩余细节时更新进展，”Toolie 说道。好吧，这听起来就像我在为初稿向编辑争取更多时间一样。

每次我们要求 Dots agent 改进它的选择时，沙发看起来都更接近我们真正会为客厅购买的东西——既实用又引人注目的家具。既可爱又舒适。

尽管在与 OpenAI 的 agent 长达一小时的互动中，我们当晚并没有最终下单，但我还是保存了一些链接以备后用。机器人犯了一些错误，但结果还是可靠的。我还要求 Toolie 监控沙发网页，如果有任何一款打折就提醒我。

这些与我的 Dot 的互动捕捉到了使用这款软件的精髓，但在测试过程中，我还遇到了一些其他奇怪的时刻。最值得注意的是，当我要求 Toolie 检查我的订阅并取消不必要的订阅时，它标记了我定期在 TikTok Shop 订购的益生菌苏打水为可取消的候选。

“TikTok 的网站有一个拼图验证码，挡住了 Wildwonder 的取消操作，”Toolie 说。“我可以来解吗？如果你愿意，也可以授权我以后自动解决验证码。”我笑了笑，鼓励这个机器人试试。Toolie 失败了，并建议我自己去解验证码。好吧，这倒也合理。OpenAI 的发言人表示，在用户批准操作的前提下，Dots 有时能解决这类验证码，同时会牢记“滥用防护措施”。

我最初那次买沙发的实验，只测试了 Dots 设计功能的一小部分。例如，这个 agent 可以控制你的笔记本电脑，把用户生活中更多方面自动化。

OpenAI 声称，这个机器人会随着时间推移越来越了解我，开发者们也在进行大量改进。所以，相比这两天的实验，Toolie 在每天使用两周后可能会成为更得力的帮手。这与我对 ChatGPT 记忆工具的体验如出一辙：它每周都更擅长理解我的意图。

在我看来，Dots 最像 OpenAI 最初为 ChatGPT 加入网页浏览功能时的样子。当这个聊天机器人在 2023 年上线后不久尝试搜索网页时，用起来有时令人沮丧，而且该工具会编造链接。如今，网页浏览在 ChatGPT 中运行得相当顺畅，其输出也包含大量准确、有用的链接。OpenAI 的新 agent 可能会走上类似的轨迹：起初磕磕绊绊，但在接下来几个月里会有明显改进。
