工具： Gemini 3.8 TTS Playground

Google 今天发布了两款新的 Gemini 文本转语音模型——gemini-3.8-flash-tts 和 gemini-3.8-flash-lite-tts。

它们自带一个包含 2,000 多种声音的语音库，还能用“仅仅 30 秒的音频样本——你自己的声音，或者你有权使用的声音”来创建自定义语音。

我用 GPT-6 Astra vibe coding 出了这个自带 API key 的 playground 界面，利用了底层 Gemini API 开放的 CORS 策略。

这个 API 的一个显著特点是，它很容易定义多个角色之间的完整对话，每个角色都有不同的声音和语音风格指令。

下面是一段简短的演示片段，内容是两只鹈鹕在争论要不要搬到 Pacifica Pier。我让 Claude 4.5 Opus 写了脚本，并生成了一个用该工具渲染它的 URL。

使用 Gemini 3.8 Flash TTS（不是更便宜的 Flash-Lite）生成 1 分 18 秒的音频大约花了 20 秒，成本为 2.74 美分。
