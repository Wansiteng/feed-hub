让互联网对 AI agent 更友好，可能对其他人更糟

MIT Technology Review · 评分 7/10：讨论 agent 与网络生态的实质分析，与 agent 兴趣相关
原标题：Making the internet better for AI agents might make it worse for everyone else

要点

  • 个人 AI agent 大规模上线，agentic 网页流量 8 月至 9 月翻了三倍
  • OpenAI 的 Dots 和 Meta 的 Muse 等应用让 agent 走进普通用户
  • 许多网站开始封禁 AI agent，亚马逊已封禁 Muse 并起诉 Perplexity

本文最初发表于我们每周的 AI 通讯 The Algorithm。想第一时间在收件箱收到这类文章，请在此订阅。

直到不久前，你还可以把互联网用户只分成两类：机器人和人。长期以来，网站允许机器人执行自动化任务，比如抓取网页内容，但有规则约束它们能访问什么、如何行事。毕竟，网络主要是为人设计的，即便我们偶尔得解谜题、过验证码来证明自己不是机器人。

但个人 AI agent 的发布正在彻底颠覆这一切——它们能替你在网上办事，比如订机票或酒店房间。随着 OpenAI 的 Dots 和 Meta 的 Muse 等应用上线，这类 agent 最近开始大规模涌现。Muse 上线首月下载量达 500 万次，agent 产生的网络流量从 8 月到 9 月增长了两倍。

这些 agent 与人类访客混在一起——而互联网的设计主要是优先服务人类——结果并不理想，许多网站封禁了消费者派来议价或规划度假的 AI agent。不过，如果对 agent 的需求持续上升，互联网将越来越多地为它们而非我们重新设计。

这类变化正在到来，因为 agent 确实标志着第三类网络访客。它们当然不是人，而且以机器速度使用互联网。但它们也不完全是机器人，因为它们代表个人执行完全正当且有用的任务，只是比人快得多。

由于 agent 无法套用我们现有的区分机器人与人的系统，一些平台（尤其是更注重安全的平台）干脆选择全面封禁它们。TechCrunch 最近报道，人们发现自己的 agent 在从必胜客到 Yelp 的各类网站上部署受阻，Yelp 不允许 AI 预订餐厅。亚马逊封禁了 Muse 的 agent，并正与 AI 初创公司 Perplexity 打官司，试图同样封禁其 agent。尽管法官最近判 Perplexity 胜诉，亚马逊已提起上诉，称 AI agent 让人更难区分人类看到的广告和投放给机器人的广告，从而威胁其广告业务。

这些封禁让早期使用者很恼火，但宾夕法尼亚大学沃顿商学院副教授伊桑·莫利克预测，这很快就会影响整个网络。例如，一旦人们普遍知道可以派 AI agent 去申请退款或议价，agent 就会淹没客服部门，导致真人无法使用这些服务。他最近在 LinkedIn 上写道：“当人们发现自己的 agent 不被允许代劳时，最终会非常恼火。”

如果个人 agent 的需求增长，平台会想办法让它们进来。这一点尤其明显，因为 绝大多数 agentic 网络流量都流向电商网站，这意味着如果平台允许大批新的 AI agent 代表真人购物，就有钱可赚。事实上，电商巨头 Shopify 已经在 欢迎这些 agent，为它们提供专属结账通道，绕过为人类设计的页面。

紧迫的问题是，在这个过程中，我们其余人的互联网会变成什么样。我们已经习惯了一个这样的网络：尽管它越来越被设计来利用我们的注意力，但人类至少仍是预期的用户。但那个互联网可能会让位于一个为最终将超过我们数量的 agent 而优化的互联网，让剩下的人类更加痛苦。

这可能会怎样发展？也许网站作为真人目的地的地位会日益被忽视。想要自己浏览和比较产品的人类会遇到更糟糕的界面。验证系统并不完美；想象一下，你不断被要求验证自己是人类而非 agent（嘿，也许你需要 扫描虹膜 才能做到）。你想要的那件毛衣不是对所有人标一个价格，而是对不同人的 agent 显示不同价格。你永远无法判断你的 agent 的推荐是否受到广告或平台佣金的影响。

这与 Google、Anthropic 和 OpenAI 所承诺的未来相去甚远——在那个未来里，AI agent 将赋予消费者更大的权力和议价筹码。但这个承诺并非天方夜谭。例如，agent 能够通过对抗虚假医疗账单或研究更实惠的汽车保险来 真正帮助人们。

它们能否 真正 用于这些目的，取决于为 agent 如何与网站交互以及它们究竟被允许做什么而制定的规则。

这些规则仍在制定中。其中一些将惠及我们所有人——例如，无论是消费者还是企业，都不希望 agent 在网络漫游时到处挥舞信用卡信息，而让 agent 更安全的规则是好事。更具争议的规则，比如企业是否可以阻止 agent 访问其网站，或阻止它们为消费者争取更优惠的交易，将决定网络是成为为我们工作的 agent 的高速公路，还是成为与我们作对的 agent 的高速公路。
