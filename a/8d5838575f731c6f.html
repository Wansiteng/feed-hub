Instinct 曾是热度最高的 AI agent——它能挺过 Muse 吗？

The Verge · AI · 评分 6/10：AI agent 创业公司竞争动态，有实质信息
原标题：Instinct was the buzziest AI agent around — can it survive Muse?

要点

  • Instinct 以邀请制、无营销方式推出 AI agent，9 月底估值达 100 亿美元
  • Instinct 通过 iMessage、WhatsApp 或邮件对话，无独立 app 和订阅费
  • 测试中 Instinct 能完成预约、退货等任务，但会漏掉网页弹窗里的关键信息

在那些可爱小家伙出现之前，先有 Instinct。

今年 8 月，这家初创公司以一种不同寻常的打法把自家 AI agent 推向市场：仅限邀请、不做营销，甚至连个像样的网站都几乎没有。然而 Instinct 迅速成为 AI 圈最热门的话题，凭借其直截了当的、基于短信的交互界面，以及处理诸如预约 DMV 办事、发送跟进邮件等琐事的能力而广受好评。

随后 Muse 登场，不久之后 Dots 也来了。来自两家实力远为雄厚的公司的产品，或多或少是同样的东西。

随着大科技公司突然入局，这家初创公司靠一场热闹的发布能否保持领先，一度显得颇为可疑。但在我自己的测试中，Instinct 与另外两个 agent 相比并不逊色，处理在线任务的表现已经达到一个机器人所能达到的水平。而 Instinct 的创始人 Noah Shinn 对日益激烈的竞争并不慌张。

“AI 助手就是我们知道的全部，”Shinn 在邮件中对我说。虽然 OpenAI 和 Meta 为各类客户打造 AI 产品，但 Shinn 认为 Instinct 的专注让它与众不同。“我们一直只专注于打造一个真正懂你的日常生活个人助手。”

Shinn 曾是 Sierra 的早期员工——那是另一家拥有深厚硅谷血统的高估值初创公司——之后他自立门户创办了 Instinct。这次低调的发布迅速升温，收获了测试者的赞誉和投资者的大力背书。即便在 Muse 发布之后，该公司仍在 9 月底估值达到 100 亿美元。目前没有 app，也没有月度订阅费。你要么需要现有用户的邀请，要么需要等待名单的批准。我只等了几个小时就获批了。

Instinct 的 AI 助手能做的许多事情，和我让 Muse 帮我做的差不多，某种程度上也包括 OpenAI 的 Dots。那些生活管理类任务，比如报名游泳课、确认预约，在一个有一个学龄前孩子和两个全职工作成年人的家庭里，会以惊人的频率堆积起来。这些是过去一年软件开发者一直在使用的 Codex 和 OpenClaw 之类 agent 的、更面向消费者的版本。

你和它们聊天就像和聊天机器人聊天一样，但它们还能访问一台虚拟机，并接入你的个人邮箱和日历。Muse 那只毛茸茸的熊吉祥物和 Dots 那些拟人化的小团块，感觉明显是在试图吸引更广泛的消费者群体，而 Instinct 给人的感觉截然不同。

与 Instinct 的 agent 的对话通过短信进行——可以是 iMessage、WhatsApp 或电子邮件。没有可爱的小家伙。也不假装它正坐在笔记本电脑前敲键盘。只有简短的回复、偶尔的 emoji 反应，以及远多于言语的行动。它已经达到了我认为我们目前对 AI agent 所能合理期待的有效程度，但一个机器人在人类世界里把事情办成，其局限也同样真实。

如果你想让 Instinct 登录某个特定网站，你会收到一个链接，让你在“安全保险库”中输入详细信息，你还可以将它连接到不同的服务，包括你的 Google Workspace、Slack 和 Notion。但除此之外，界面就只是你的短信。这有点天才，这意味着只要你能收发短信的地方就能使用 Instinct，比如 CarPlay 或你的手表上。它就安静地待在附近，这要么很理想，要么很诡异，取决于你对 AI agent 的感受。我觉得两者都有一点。

Shinn 表示，缺少传统应用界面是他认为 Instinct 与大型玩家区分开来的关键部分。“虽然 AI 平台擅长回答问题 and 提示，但 Instinct 无缝融入人们的生活，将对话转化为行动，”他说。“就像你会给你的私人助理发短信或电子邮件一样，你也可以对 Instinct 这样做。”

Instinct 一开始并没有让我印象深刻。在几条介绍性消息之后，它把我的辛辛那提区号当作邀请，给我发了一个《Enquirer》网站的链接，以及一组 CVG 和 SFO 之间的航班搜索结果。谢谢？我告诉它我不再住在辛辛那提了。“哈，”它说。“记下了——从现在起我会记住这一点。”但在过去几周里给它喂了一连串有实质内容的 task 之后，它让我印象深刻的次数多于不深刻，尽管我不认为我更接近实现某种生产力涅槃。

我给 Instinct 布置了一个有点模糊的任务：为我儿子找游泳课——这是我多年来一直想做但似乎总是拖延的事情。我让它找适合他年龄的课程；它返回了一份可行的结果列表。我建议去附近的社区中心，它便调整方向，专注于那里。我打开浏览器，跟着它的建议核对。它给出的时间和日期都核对无误——一个非常低的门槛通过了。但它漏掉了一个关键信息：该中心对报名学前班课程的孩子有一个先修课程要求。我碰巧注意到了这个细节，这凸显了 AI agent 面临的一个挑战：它们擅长处理干净的数据集，但互联网是人造的，数据往往很糟糕。有时关键信息就藏在一个弹出窗口里。

Instinct 还很好地处理了其他几项任务，比如给我的眼科医生办公室发邮件预约，以及完成宜家退货的数字文书工作。除了帮我填写一些表格之外，它出人意料地擅长处理模糊指令。我让它搜索我过去的宜家购买记录，它弄明白了我说的“它是垂直的、白色的，有点像这些树枝一样伸出来”指的是什么产品。（Tjusig，给那些在家记分的人）。

有几次它让我惊讶，因为它提供了我没有明确要求的相关信息。我开始请求给眼科医生发邮件时，承认我不记得诊所的确切名称。Instinct 根据我的描述缩小了范围，后来在对话中它指出我有一封 2024 年来自该医生的确认邮件，只是为了让我放心，我让它发邮件的地方是正确的。另外，Instinct 在为我做另一件杂事时，还标记了我日历上的一个潜在冲突。像一台大型、花哨的自动填充机器一样填写表格是一回事，AI agent 正迅速证明它们在这方面相当擅长。但正确识别相关信息并主动引起我的注意，感觉像是朝着真正帮助迈出的一步。

未来这些都要付费了。当被问及 Instinct 是否会保持免费时，Shinn 回应称：“Instinct 对受邀用户免费。我们的意图是尽可能让它保持可负担。”Techsponential 的分析师 Avi Greengart 指出，像 Instinct 这样由风投支持的公司，当前的首要目标是增长。“其商业模式就是尽可能快地增长，从而建立起值得付费的东西，”他说，并指出像 Instinct 这样的公司可能着眼于来自其客户群的收入，和/或被更大公司收购。

OpenAI 的 Dots 目前仅对付费订阅用户开放，而 Meta 的 Muse 则可免费使用。“如果你不为它付费，那么你所寻求的商品和服务可能正在通过某种交易来获取你的 agent 访问权限，”Greengart 推测道。他承认，当前的经济模式有些不太合理，因为目前 agent 主要由早期采用者使用，但他认为那句老话依然成立。“如果你没有直接为它付费，那你就是在间接为它付费，”他说。

据 IDC 高级总监 Greg Ireland 称，这可能意味着未来会有更多广告。“这些 agent 如此侧重于交易、商务或购物，这恰恰使其成为天然的契合点，”他说。事实上，Instinct 已经尝试过向用户推送“推荐产品”。企业有充足的动力让这类广告对消费者来说可以接受，但 Ireland 认为广告无论如何都会发挥作用。“消费市场中的所有道路最终都通向广告，”他说道。
