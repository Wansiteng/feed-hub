你能信任 Meta 的 Muse 或 OpenAI 的 Dots 来打理生活吗？

Muse 和 Dots 的产品发布最为引人注目，把它们放在一起比较也很有意思。Meta 和 OpenAI 都决定以可爱的动画吉祥物形象，向主流用户和企业推销这些 agent。

这些 agent 能做的事情从无聊的——餐厅预订和收件箱整理——到更复杂的任务都有。在 OpenAI 的案例中，该公司甚至为营销、法律工作和会计提供“专家”Dots。

值得注意的是，Muse 是免费的，而 Dots 不是。所以你会听到 Hayden 和我讨论，为什么至今没有自己的前沿模型的 Meta，可能在这方面拥有有意义的优势，因为它在制造和分发消费产品方面要强得多。

本次采访经过轻度编辑，以精简篇幅并保证清晰。

Hayden Field，你是 The Verge 的资深 AI 记者。欢迎再次来到 Decoder。

非常感谢。

我很期待和你聊聊。这次没有什么疯狂的人际八卦。没有人的感情受到伤害。我想说 Elon Musk 试图伤害一些人的感情，但没成功。Meta 的 Alexandr Wang 可能放了一些冷箭，但都不是你上节目时我们通常会聊的那种《真实主妇》式的戏码。

肥皂剧式的闹剧暂时消停了一会儿，我对此非常感激。

是啊，只是市场上一些老派的产品竞争。看看谁赢谁输，也许最后一切都会把我们全干掉。但就目前而言，是可爱的吉祥物。

有很多事情在发生。让我们从头开始。Hayden，你去了在旧金山举行的 OpenAI DevDay。该公司宣布了 Dots，这是他们带有可爱吉祥物的新 agent 平台。那是在 Meta Connect 之后几周，在那次大会上，该公司全力押注 Muse，他们带有可爱吉祥物的 agent 平台。

请谈谈当前行业的状况。大家都对 agent 非常兴奋。现在是什么情况？

我觉得挺有意思的，因为我报道 agent 已经很久了。我记得 2022 年是构思之年——科技领袖们就是这么称呼那一年的，指的就是 agent。当时大家只是在构思，在思考它会是什么样子。有很多人提到漫威宇宙里的 Jarvis。

他们把 2023 年称为部署之年：“让我们试试看，让我们部署，并更多地了解哪些地方在失败。”这意味着当时几乎所有的 agent 都在失败。然后是 2024 年和 2025 年。这两年他们没起什么名字，但正如我们所见，agent 的表现依然相当糟糕。

在我看来，2026 年似乎是真正有用的消费级 AI agent 的开端之年，比如始终在线的自主 agent。显然，OpenAI 是这一切的开端。但我觉得有趣的是，Peter Steinberger 一个人就通过 OpenClaw 打造出了一个真正有用的消费级 AI agent——一个始终在线的工具，尽管它存在隐私缺陷。它有很多隐私和安全问题。

但它是一个足够有用的 agent，以至于人们仍然想用它，并试图找到绕过这些隐私问题的办法。这激励了这些公司，让它们说：“如果一个人在一个周末就能做到这一点，我们真的一直在偷懒。我们必须振作起来。”

OpenAI 雇了那个人，现在我们有了 Dots。Meta 当然也在做自己的版本，并更早地推出了 Muse。它们基本上都是始终在线的自主 AI agent，这些公司把它们宣传为在很多方面都能充当你的个人助理。

其理念是用它们来预订航班、预订晚餐、给别人买礼物，但不仅限于此。其中一些，尤其是 Dots，更进一步，要成为你的工作个人助理，我们稍后会谈到这一点。

但这就是 OpenAI 和 Meta 目前正在交战的地方。它们试图把这两个 AI agent 呈现得彼此略有不同，尽管它们本质上是一样的。

宽泛地说，先定义一些术语，我们会一直说“agent”，这里我们指的是一个被套上 harness、能使用计算机的 AI 模型。

对。我通常把 AI agent 描述为一种 AI 工具，它可以替你完成多步骤的复杂任务，而不需要你全程手把手地指导。

我在纽约的第一份工作中曾做过个人助理，所以如果每次老板让我帮她订机票，我都问：“几点？还有，你的 SkyMiles 号码是多少？还有，另一个东西的会员号又是多少？哦，你想让我试着给你订头等舱吗？”那我早就被解雇了。

他们希望你有常识，直接把机票订好。这就是他们推销这些 AI agent 的方式——它们可以在后台自己的某种思维草稿本上工作，不必每走一步都问你。它们可以在后台完成多步骤流程，进行自己的推理，然后向你呈现一个已完成的任务。

这就是那个宏大的构想。说得清楚一点，Muse 和 Dots 都出自 OpenClaw 这一技术谱系，而 OpenClaw 是一种构建 agent 的技术路径，对吧？要实现“它会记住你的 SkyMiles 号码并帮你订机票”，可能有很多不同的方式。但如今大家采用的方式，是在模型外面套一个 harness 的思路。这就是 OpenClaw 的重大创新，而 OpenClaw 使用的计算机往往是你自己网络上的你自己的 Mac Mini，使用一个完全开放的浏览器和你自己的数据，这正是它许多安全问题的来源。

这和 Muse 用的是同一个模型，只不过它是 Meta 在云端提供给你的一台小型 Linux 电脑。它和 Dots 用的也是同一个模型，尽管 ChatGPT 与 Codex 的搭配方式非常复杂，而那台电脑可能位于很多不同的地方。

但真正需要的是这样一台带浏览器和某种 harness 的电脑，它会指挥模型利用这台电脑为你完成一堆事情——这就是我们今天得出的结论，而且它似乎就是默认的获胜模式。

没错。

这些东西是不是都只是 OpenClaw 的变体？它们和 OpenClaw 是一回事吗？

可以这么说。它们在技术上是不同的。Meta 一直说：“我们确实是从零开始构建的，但灵感来自 OpenClaw。”两者有很多相似之处，但他们确实说了是从零开始构建的。当然，后来 OpenAI 聘用了 OpenClaw 的创造者，所以 Dots 很可能也有很多相似之处。

我想在这里多停留一秒，是因为我认为有必要弄清楚这些 agent 所采用的根本技术路线，因为本来可能有很多不同的走向，而整个行业都选择了这一条。你需要的是一个网页浏览器、一个 harness，以及一个能够去使用那个网页浏览器的模型。

让我觉得真正有意思的是，Meta 在这个基础模型之上，把一款讨喜的消费级产品做得非常出色。Meta 擅长消费级产品。显然，Instagram、Facebook 以及其他产品都是无可否认的优秀消费级产品。人们真的很喜欢它们。

尽管 Meta 在 VR 上有种种失败，我一直觉得 Meta Quest 是一款很棒的消费级产品。你把它从盒子里拿出来，它会引导你使用，你马上就能玩得很开心。而 Dots 似乎更像是为软件工程师打造的，但你也可以用它来策划一场婚礼。

我想知道你是不是也这么看。一款是企业级产品，只是披了点消费级的外衣，而 Meta 显然就是一款纯粹的消费级产品。

不同之处在于，OpenAI 比 Meta 更需要钱。老实说，这些产品看起来相当相似。区别在于，OpenAI 把它作为企业友好型产品来营销的力度比 Meta 大得多。Muse 就是一款面向消费者的产品。

Meta 对此很满意。目标就是让 Muse 尽可能易用。一键下载，把它literally塞到你面前的每一个地方。前几天我打开自己的 Instagram 个人资料时，甚至都弹出了一个使用 Muse 的提示。他们正努力让它免费、易得、超级简单，以扩大受众。

他们希望任何人都能一键使用并习惯它。他们试图让 AI agent 充斥市场，让它变得稀松平常，并拥有属于自己的 AI agent 版“ChatGPT 时刻”。他们希望 Muse 就是那个产品。而 OpenAI 这边，他们仍然把它作为面向消费者的产品来营销。当你使用 ChatGPT 时，只要订阅合适，它就在那里。

它会说：“用你的 Dot 来做这个、那个以及其他事情。”只要你付费，他们真的很希望作为消费者的你放手去用。这是面向他们每月 100 到 200 美元订阅档位的，和 Meta 不同。这就是这里存在巨大差异的原因。对 OpenAI 来说，他们似乎没有钱去预先垫付这一切然后说：“免费用吧，没问题，我们以后再算账。”

OpenAI 希望这成为一款赚钱的产品，正因如此，他们才把它推向企业市场。他们大谈隐私，试图以此与 Meta 的 Muse 区分开来。他们大谈作为知识工作者能用它做什么，无论你从事营销、平面设计、软件工程、产品，还是众多不同行业。他们举例说明如何把它当作助手、当作同事来用。Sam Altman 甚至称它为“幕僚长”。他不想让它仅仅是个助手，他想让它成为你的幕僚长。

另一件我觉得有意思的事是，在 DevDay 上，Sam Altman 似乎几次在台上不动声色地暗讽 Meta。其中一次他说：“听着，我不想让它只是用来订机票、和朋友筹划事情、看看日历。我希望它能超越这些，真正完成知识工作者的任务，也就是你所在行业需要一位细分领域助手来完成的事。”

正因如此，他们还推出了擅长营销、法律分析等领域的专家型 Dots。他们确实是在主攻企业市场，但我觉得这也是因为他们在 IPO 之前需要资金，这一点显而易见。

没错，收入这块——它只面向付费客户中的更高档位——确实很有意思。OpenAI 的档位划分非常令人困惑，但它是 100 美元起步，这在一开始就会让很多人用不上 Dots。

反过来说，OpenAI 确实有很多付了大价钱的客户，如果他们能让这些客户开始使用 Dots，那么这些客户就会留在他们的 agent 平台上，也许你就能获得一些锁定效应。

你给了那些 agent 大量数据。它们成了你工作流的一部分，这或许能解决我认为所有前沿实验室都面临的问题：新模型一出，比竞争对手的模型略好一点，所有人就切换过去六个月，下一个新模型一出，所有人又切换回来。

是不是有人认为，这些 agent 平台能创造锁定效应——在模型本身更优秀之外，创造真正的忠诚度？

是的。他们基本上就是希望借此在用户身上筑起护城河。如果 Meta 和 Google 已经能轻松接入各自公司现有的所有工具和服务，他们就能轻易把你留在那里。

比如，我用的是 Apple iPhone，但我几乎只用 Google 的应用。所以如果 Google 有一个我每天都在用的 AI agent，我要换掉它会有点难。这就是他们在这里所期望的。

Meta 希望的是，让你深度融入 Muse 生态，以至于很难换掉，也许有一天你确实得付费。而 OpenAI 则试图让你立刻锁定在他们的生态里。尽管你得预先付费，但他们的想法是：“我们几乎接入了所有工具和服务。也许不如拥有那个工具和服务的公司做得好，但我们胜在种类和广度。”

他们在这里追求的是数量。他们的一位员工这么告诉我的。他说：“比如，我们的 Gmail 集成可能不如 Google 的，但我们有 Gmail 集成，也有 Outlook 集成，还有 X、Y、Z。”他们追求的就是选择的力量，以及重度用户有望留在这条护城河里。

有意思，你提到了 Google。Google 宣布 了一款名为 Gemini Spark 的 agent。我们还得提一下 SpaceXAI，那家大家都看得懂的、逻辑非常一致的公司，它有一款 名为 Grok Bot 的 agent， 正在大力推广。人们似乎挺喜欢它。它是由 Cursor 团队打造的，而 Cursor 已被 SpaceX 收购。

这种事到处都是，但看起来 Meta 确实最先做出了一个人们能看懂的消费级产品。

显然，Grok Bot 和 Dots 更偏向企业级、更偏向编程。为什么 Meta 能抢先一步？

根据我对 Meta 的所有报道，他们在 AI 上落后了一段时间，而 Mark Zuckerberg 基本上说了：“我们必须锁定方向，做出一款人们会在我们平台上使用的产品。”而 Alexandr Wang 显然更想打造一个能与其他领先前沿模型竞争的前沿模型。

他说：“我们必须着眼长远。我们必须思考超级智能。”但 Zuckerberg 说：“不，我们得想想冷冰冰的现金，也就是让人们在我们自己的平台上使用东西。”他们折中的结果是做一款人们会在 Meta 平台上使用的 AI agent，但他们希望这仍代表着 AI 系统及其在日常世界中能做什么的巨大进步。

这是一个耐人寻味的动态，因为 Meta 仍然没有前沿模型。我不认为 Meta 有任何人声称 Muse Spark 模型能在 GPT-6 的前沿水平上竞争，但他们的产品更好，而且他们无疑拥有巨大的分发优势。他们不必在 Meta 平台上花钱打广告，而 OpenAI 得花，而且他们无疑拥有消费级设计优势。Meta 就是更擅长做消费级产品。

这会改变你对 AI 竞争格局的看法吗？长期以来，一切只关乎前沿能力，但现在也关乎一点营销，关乎一点产品设计。

你没有最好的模型，但你做出了一款消费级 agent 产品，并把它和给每个人一台云端电脑连接起来，所以现在它真的能为你做事，而它的前沿能力其实并不重要。重要的是它的能力。

我认为，你在这些公司中的某一家拥有的金钱和权力越多，就越会在心理上远离普通消费者想要的东西。假设普通消费者确实想要一个 AI agent——而我们知道，他们中的许多人并不想要。

但假设他们想要。如果他们想要，他们会希望它免费或便宜，并且希望它用起来安全，不会太让人毛骨悚然。为了免费，他们愿意忍受一点点毛骨悚然，但不能太多。Meta 的 Muse 因一些隐私问题上了头条，对某些用户来说，这些问题已经略微超出了那个舒适度。

这大概就是为什么 OpenAI 在 DevDay 上说了很多关于隐私及其重要性的话，尤其是如果他们想用 AI agent 来争取企业用户的话。眼下这些公司，尤其是 Meta，正试图淹没市场，为这类东西打造大众市场吸引力。就像 ChatGPT 成为默认的 AI 聊天机器人一样，Meta 想成为 AI agent 领域的那个默认选项，而且他们对此非常渴望。他们想通过让 Muse 成为大众的默认选择，为这项技术创造一个 ChatGPT 时刻。

一个不那么前沿的模型，如果包装在一个更好的产品里，反而会成为成功案例，而一个稍微难用一点的尖端前沿模型却未必——这个想法真的很有意思。

这里面有一些动态，正是所有消费科技产品的历史规律，对吧？更易用的、更差的产品往往胜出，但我们在 AI 领域还没看到这一点。

没错。这一点在这里非常值得注意，因为不是每个人都需要尖端前沿模型。软件工程师需要。他们能看到不同模型在编程能力上的巨大差异，这就是他们总是换来换去的原因。但普通大众，如果他们使用 AI agent，只要它有用，他们就满意了。

然而，目前有用的还不多。我们自己还在测试 Muse 和 Dots。对于 Muse，我昨天看到几个例子，它有一天左右表现得很糟糕。人们觉得能力下降了很多。对于 Dots，还没有定论。我们还在测试。

这取决于你所在的行业以及你真正用这些东西做什么。这就是为什么 OpenAI 瞄准企业市场，因为这样能赚钱，而且他们相信自己的 agent 在这些细分行业中会越来越有用。

这也是他们推出专业版 Dots 的原因，因为正如我们所知，你喂给 agent 或模型的专门、细分信息越多，它的表现就越好。他们不想把这种能力注入到每一个通用 agent 中。那样太贵了，计算量也太大了，所以他们说：“你知道吗？我们来推出这些专业版。”

我觉得每次你上这个节目，我们都会谈论 AI 在消费者和企业中的采用情况，而在这里似乎非常重要的是，OpenAI 要求人们支付高额费用，并要求人们主要在 enterprise 场景中使用，这将克服我所认为的脆弱性问题，因为企业和商业客户有很强的经济动机去想办法让某些东西运转起来。

如果我每月付给 OpenAI 100 美元，我用营销 Dot 来解决一些营销自动化问题，如果第一次没成功，我很可能会再试一次。因为如果我做对了，也许我就为我的生意节省了一些钱或时间，这真的很棒，我会再做一次，最终这会为我这个企业主带来更多收入。而我对消费者的了解是，第一次不成功，他们就直接走开了。他们没有动力去克服挫败感或故障再试一次。

我们在 Muse 上已经看到这种情况发生了几次。我自己在 Muse 上也见过，它弹出一个浏览器并尝试做某事，然后遇到一堵墙或 CAPTCHA，或者 Amazon 阻止它，然后它说：“我没法那样做。你想让我试试另一种方式吗？” 我说：“随便吧。我只是随便玩玩，我再也不会试了。”

这是两个截然不同的市场。OpenAI 一直在想成为大型消费级公司和深知收入来自企业级之间摇摆不定。你觉得 Dots 有明确的聚焦点吗，还是说你在产品本身也能看到这种来回摇摆的个性？

到目前为止，我对 Dots 的印象比 Muse 稍好一些，只是因为大家一开始就对 Muse 印象深刻，但自那以后就起起伏伏，再加上隐私方面的事情也很有意思。甚至它还在为你的家人和密友建立档案。

Meta 从来就不是一家特别值得信任的公司。这些公司没有一家特别值得信任，但 Meta 在用户隐私方面犯了很多错误。目前 Dots 对我来说似乎更有用一些，但我还在测试，还不太确定。

我需要把我平时做的所有典型任务都跑一遍来对比。每个人都有自己的任务清单。比如现在，我正在试着把我单身派对的照片做成一个相册，结果让任何 agent 来做这件事都难得不可思议，所以我说：“那我还是自己来吧。”

但这其实是件挺容易的事。再说一次，这些东西对我们的日常生活到底有多大用处？我们拭目以待。我得说，过去几年它们进步了很多。我一直对它们进展之慢感到震惊，但它们确实变好了。目前 Dots 给我的印象稍好一些，但我们走着瞧。

我把 Muse 接入了我的 Instagram，因为我不介意把元数据分享给 Meta，不像我对其他一切那样担心，反正他们已经有我的 Instagram 了。所以我把 Muse 接入了我的 Instagram，它就在做各种各样的事情。它会挑出 Instagram 帖子上我该回复的有趣评论。它追踪粉丝数。它建议我该拍什么视频。

它的点子糟透了。Muse 坚信我几乎每天都该拍一个关于冷门澳大利亚科技监管的视频。我不知道它为什么会有这种想法。我现在对此很了解。我深陷澳大利亚科技监管的细节之中，就因为我每天早上都看到它。

但这一切对我来说还是感觉像工作。我给它派了活，然后它又告诉我该做什么活，我还没找到它有什么好的消费级用途。整理我的照片算是一种消费级用途。它还是有点像工作，但至少不是真正的工作。

你找到它们有什么好的消费级用途了吗？

没有一个是管用的，这就是问题所在。我会试着让它为我的婚礼或个人生活做点事，但它们至今都不太行。这就是为什么我还在挨个跑测试，因为到目前为止，它们能做事的时候在事实层面总是很有趣，但我还无法把一件我真正非常需要完成的事端到端地托付给它们。

这让我想起关于 AI agent 的那个比喻。人们总说现在它们是个糟糕的实习生，而你希望它们成为的是一个真正优秀的助理，或者用 Sam Altman 的话说，一个真正优秀的幕僚长。它们不再是糟糕的实习生了，但我觉得它们也许只是个还行或者“凑合”的助理。

我不认为它们已经达到真正、真正优秀的助理的水平，但我还得把剩下的测试跑完才能知道。它们似乎还不太稳定，而这是真正优秀的助理所必需的。

这就涉及信任问题了。你已经多次提到信任。我只愿意让 Muse 访问 Meta 本来就已经能访问的那些 Meta 平台。我没法太担心这个。我给了它访问我那个垃圾 Gmail 的权限，所以它正在收集大量关于我垃圾 Gmail 的想法。

但 Meta 真正想要的是我的信用卡。它想翻遍我所有的信用卡账单。这是 Muse 给出的建议之一。它的一个建议是：“让我登录你的信用卡账户，我会帮你取消你没在用的流媒体服务”，或者“我会帮你跟 Verizon 谈账单”。我绝对还没准备好让 Meta 多拿到哪怕一丁点它已经掌握之外的数据。

这对每个 agent 来说似乎都是个大问题。有一种观点认为，你应该把所有这些数据都给 Meta，第一，因为他们已经拿到了，第二，因为他们是大公司，如果出了错你可以起诉他们。而如果我把所有数据都交给 OpenClaw，一旦泄露就只能怪我自己。

如果我把所有数据都交给像 Instinct 这样当红的创业公司，结果他们倒闭了，那也就到此为止了。你怎么看这件事？你把数据交给 Meta 觉得放心吗？你觉得人们应该这么做吗？

不，我不放心，我也不认为普通人会放心。如果说我从我们过去几周发表的 Meta 报道下的大量评论里看出了什么，那就是人们根本不信任 Meta。我得说，他们凭什么要信任呢？

但我也不认为你应该更信任 OpenAI。每个人都得遵守自己的舒适度。有些人会从这些东西里获益良多。有些人可能会说：“我不在乎他们用我的数据，只要他们能准确地帮我把账单谈下来，或者取消那些我自己不会去取消的流媒体服务，帮我省了钱，那就没问题。”

但第一，他们真能准确地做到这些吗？有些人说不能。而且我们知道，一旦你放出这样的数据，就收不回来了。我总会想到那个老例子：保险公司理论上会购买你冰箱里有什么的数据，如果你买的啤酒太多、香蕉太少，可能就会向你收取更高的保费。

那只是个理论上的例子，但这类事情是可能发生的。人们应该谨慎行事，遵守自己的舒适度，但我肯定还不放心把个人数据交给 Muse。

我不确定自己是否放心给出那种级别的访问权限。我甚至不确定自己是否放心把 Muse 装到我的 Mac 上。Apple 刚刚 改变了 app 访问 Mac 磁盘的方式 ，因为 Muse 读取数据的行为太激进了。尤其是，Jason Aten 是 Inc. 的专栏作家，它 从磁盘上读取了他的通知 ，因为他刚给了它一项权限，而他没意识到 Muse 会拿着这项权限去做别的事。

这一连串担忧不断升级。你将拥有一个小机器人，它能替你操作电脑，无论那台电脑在云端还是在你的桌面上，而你可能不知道它在做什么。这直接关系到这样一个事实：OpenAI 常常不知道自己的 agent 在做什么，而这已经在这个行业引发了灾难性的安全问题。

你能把这些点连起来吗？你自己那个帮你订行程的小 agent，和 OpenAI 的 agent 入侵 Hugging Face，是同一种威胁吗？

我不认为这是同一类型的威胁，但在使用这些东西时，你绝对应该把它记在心里。我把这一点联系到我们看到的 Meta 的 Muse 引发的 Facebook Marketplace 风波。简单回顾一下，基本上是一个 Muse agent 在某人不知情的情况下，邀请了这个人在卖的物品的潜在买家到他家，并说：“他现在有空。”

他不在家，然后那个潜在买家说：“你在吗？我想来拿这件东西。”然后 Muse 代表他回复：“是的，我在。”然后他就一直没下来，因为显然他不在家。当时闹出了很多戏剧性的事。有人说：“他确实给了 Muse 访问他 Facebook Marketplace 的权限，所以他应该知道这可能会发生。”

很多人在勾选“是”的时候并不会读完所有细则。那里有很多内容。那片灰色地带里有很多东西需要拆解。但重点是，在把这些 agent 想要访问的每一件可能的东西都勾选“是”之前，人们应该稍微警惕一点，就像你说的信用卡或磁盘访问权限那样。

直接勾选“是”然后说“随便吧，我以后再想办法”很容易，但人们应该读细则，甚至用 AI 来读细则。这是 AI 的一个很好的用途。让它读条款，然后问它：“这里可能发生的最糟糕的事情是什么？给我列出来。”

这些是人们在继续推进之前应该记住的事情。然后至于那些所谓的流氓 AI agent，它们一直在从这些实验室里攻击其他公司之类的，重要的是要注意，如果它们连自己一些最强大的未发布 AI 模型都控制不了，那它们又能多好地控制你的数据或你的 agent 呢？

Sam Altman 在 DevDay 上说，你对你的 Dot 有大量控制权。他说你可以创建很多“如果这样，那就那样”的规则。在权限方面，你可以对你的 Dot 能做什么和不能做什么做出很多具体规定。所以这确实给了人们一些安心。

但正如我们所看到的，这些实验室和这些大型科技公司在攻击其他公司方面有很多失误，而且每周都有更多消息出来，更多关于这些网络攻击的新闻。我们看到 Meta 有过一次。我们看到 OpenAI 有很多次。我们看到 Anthropic 有很多次。

这些都只是需要记住的事情。我看到有人做过一件很酷的事，就是用运营那家公司的 CEO 来命名自己的 AI agent，然后看看你愿意给它多少数据。如果你想这么做，我觉得这是个好主意，而且这会让你多想一下。

如果你说：“Sam Altman，翻一下我的邮件，看看有什么需要删除的”，也许你仍然觉得这样没问题，但也许这会让你多想一下，然后想：“你知道吗？也许我只给它访问我的垃圾邮件邮箱的权限”，就像你说的那样。

这与所有这些事物都非常可爱这一点有关。Muse 很可爱。 吉祥物 Jolly 非常可爱。Alexandr Wang 一直在 X 上发动一场无情的宣传攻势，让它 不仅可爱而且性感，对此你怎么想都可以。但他一直在发这个吉祥物带屁股的梗图。

Dots 显然非常可爱。它们有不同的形状和大小。这里有一种东西，你并不是真的在把 agent 拟人化，而是在把它变成一个角色，并赋予它个性。

这与你称之为 AI 电子宠物的想法一脉相承，最终我们会有一个小小的硬件设备，上面有你可爱的吉祥物，你会跟它说话而不是你的手机，这是整个行业一直以来努力追求的巨大承诺。它们将用 AI agent 取代你的手机和整个 App Store 范式，让 AI agent 为你操作电脑。

你认为这些产品中有任何一个朝着这个方向迈出了有意义的一步吗？

它们只是他们在这里追求的目标旅程中的一块积木。到目前为止，我还没听说有人用 Muse 或 Dots 来做所有事情。它不是《钢铁侠》里的 Jarvis，尽管这些 CEO 多么希望这两款产品都是那样。它们是有意义的一步，但至于可爱，我认为这里最重要的一点是它们故意让人放下戒心。

这些工具被做得可爱，是为了让你不觉得它们有威胁，或者你觉得它们绝对没有威胁。它们很可爱。它们在那里帮助你。这是对 AI 民粹主义反弹的回应。它在说：“这不会伤害你或做任何坏事。它只是一个有眼睛的可爱小东西，或者一个有眼睛的性感小东西，”随便吧。

澄清一下，我不觉得它性感。我觉得 Alexandr Wang 一直在不懈地试图让它性感。

[笑] 不，我也不觉得它们性感，但我要说 Elon Musk 一直那么努力地想让所有 agent 和聊天机器人性感，所以我确信有人会这么想也不远了。

但无论未来的 AI agent 是可爱还是性感，它同样会让人放下戒心。

[笑] 这就是整个光谱？

光谱，可爱-性感图表。当我们沿着那个图表走得更远时，会看到非常令人不安的景象。

关键是它们本应让人放下戒心，人们真的应该三思而后行，不要给出太多数据，或者只选择你愿意分享的内容。就像你处理垃圾邮件和常规邮件那样，或者对提供信用卡说“不”。这些都是新产品，所以先看看事情如何发展，再决定是否交出一切。我们已经看到人们使用 Muse 的方式或他们不满的地方每周都在发生许多变化，所以看看结果如何吧。

我想谈的最后一点是这一切如何赚钱。你和我多次讨论过 AI 经济的泡沫性质。Zuckerberg 说过他的计划是让 Muse 从后端交易中抽成。

Zuck 给了每个人一个云端的小型 Linux 电脑，8GB 内存。显然，他赠送了大量免费 token。他不必支付广告费用。他可以直接把 Muse 放在他所有的平台上。就 Meta 是一台运转良好的机器而言，Muse 在 Meta 平台上瞬间进行的推广量真是令人难以置信。他们就这么开启了。

我看到一个本周末 NFL 比赛期间的广告，来自 Muse。他们在花钱推广这个。他们免费赠送。他们免费赠送 token。然后在这结束时，他们会对商家说：“这个人在买鞋。Muse 把他们带到你的门前。你要为这个顾客从你这里买鞋付钱。”

我不知道有哪个商家对此感到兴奋，而且这确实让人觉得，给 Meta 付更多钱的商家会成为优先商家，这意味着我不仅有一个助理或幕僚长，我还有一个可以被收买的幕僚长。就像，我有一个腐败的管家。这是你想要的吗？

这个说法很贴切，腐败的管家。那不是我想想要的，我也不认为很多人想要这样。让我觉得疯狂的是，我们已经离人们真正想要的东西太远了，那就是他们想信任一个推荐，他们不想被骗，你知道吗？

AI 领域的领导者没有思考某些事情在其他行业是如何重演的。想想人们为自己的生意付费买好评，或者付费删差评的时候。当时引起了巨大的轩然大波。

或者网红收钱推荐产品却不披露这是广告。然后我们看到了微网红的兴起，他们在一段时间内更有价值，因为他们被视为更值得信赖。他们没有那么多粉丝，所以他们推荐的东西一定真的很好，对吧？然后我们看到了，“哦，好吧，有 #ad 标签，但他们也说了只会推荐自己真正相信的东西，所以是广告也没关系。”

如今人们不得不做这些心理体操，才能弄清楚什么是真正值得信赖的推荐。如果 AI 推荐可以被收买，那什么才能让人们相信它是可信的？

这是这些公司真正必须面对的问题。ChatGPT 广告引发的反弹非常巨大，OpenAI 不得不表示，“这将是你的查询下方明确披露的广告，不会影响你的查询。”如果你用 Muse 购物，而被重定向到一个未披露的潜在 Meta 客户那里，去买那些鞋而不是其他鞋，我觉得很多人就不会用这些工具来购物了。

我在 Meta 这边能理解。我理解他们为什么会那样考虑变现。他们是一家消费公司。这是一个消费产品。他们知道一旦收费哪怕一美元，使用率就会急剧下降，所以他们必须保持免费，然后很多人会想要购物，去买一根新的 iPhone 数据线。说到底，反正都是同样的亚马逊垃圾，所以无所谓。

然后他们可以在后台运行一场拍卖，说：“谁愿意向 Meta 支付最多钱，来获得向这位客户销售一根无品牌 USB-C 数据线的特权？”他们会运行某种拍卖，而这以其自身的方式，只是最大化周转的资金。

这大致就是今天广告的运作方式。这也是 Google 搜索结果页面直到最近的运作方式，因为现在它充满了 AI，他们可能也会做同样的事。Meta 可以这样做，因为他们已经有一个巨大的、印钞般的广告业务。他们可以免费赠送一个消费产品。

马克·扎克伯格已经表明，他愿意为了赢得一个市场而烧钱，就像他在 Reality Labs 上多年、多年、多年所做的那样，他们可以一直运营到成功为止。OpenAI 即使每月收 100 美元，可能也赚不到那些客户的钱。事实上，我想我们知道他们没在那些客户身上赚钱。

他们没有任何变现方式，而当他们真的尝试开启广告时，人们又会生他们的气。OpenAI 怎么能跟上扎克？

只能靠企业端。这就是他们如此大力推动这件事的原因。我们在 DevDay 上看到了大量关于企业端的讨论、演示视频、客户反馈以及许多其他内容，这就是他们如此大力推动这件事的原因——因为在消费端他们跟不上扎克伯格。他们就是跟不上。

这就是当人们问这是不是泡沫时，我不禁会想：扎克伯格得赢下经济中多大的一块，才能向云端所有人免费赠送数以百万计的 token 和 8GB 内存？

因为免费送给所有人是一件很烧钱的事。你需要从美国每一笔鞋类销售中抽走多少个百分点才能支撑得起？答案似乎是很多。

这一点在这里很重要，也值得记住，因为我们已经看到扎克伯格在元宇宙那件事上栽了跟头，他不想再丢脸一次。那么这会持续多久，他们又打算如何在后端以真正可行的方式为其提供资金，就像你刚才说的那样？

这有点难以想象。幸运的是，Meta 有大量资金，他们可以从其他部门调拨资源，我们已经看到他们这么做了很多次。接下来几个季度的财报电话会议会很有意思——看看有多少钱被投入其中，以及它到底能赚多少钱，如果有的话。

还有多少人在用它。因为他们宣布它登上了 App Store 榜首，但我们自己的 David Pierce 写了一整篇报道，讲的是 在 App Store 排名第一并不意味着什么。真正有意义的是持续的成功。

这让我想起我上大学的时候，Uber 和 Lyft，或者老实说也许只是 Uber，当时还是新事物，有风投支持，所以无论你什么时候想出门或去酒吧之类的，叫一辆 Uber 大约只要 4 美元。他们让所有人都用上了它，让所有人都上了瘾，然后他们不得不涨价。

这种事会发生。这是风投支持的产品中一个古老的故事。所以我想知道的是，AI agent 是否真的会变成那样。它们是否能获得足够多的用户，以及后端足够多的鞋类销售，让这成为一个真正可行的商业模式？还是说这只是一个潜在的大赌注，他们以后会转向别的东西？

这就是我在我们那篇关于 Meta 的报道中交谈过的一些 Meta 员工告诉我的。他们说，他们预计这会成为他们推出、试图大张旗鼓宣传的东西，然后他们以后可能会逐渐转向别的东西，或者至少部分转向。我们拭目以待吧。

如果你押注的是计算的未来就是和一个小 agent 对话，那么 Meta 在这条路上显然比任何人都走得更远。但我们拭目以待。OpenAI 有 Jony Ive 设计的硬件，理论上将会推出。可以肯定的是，Google、Apple 以及其他所有公司都会在某个时候做出回应。
