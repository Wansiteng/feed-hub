全面就绪：全球 PC 应用生态已为 NVIDIA RTX Spark 做好准备

NVIDIA Newsroom · 评分 7/10：英伟达新超级芯片，128GB 统一内存与本地 AI 算力值得关注
原标题：All Systems Go: Global PC App Ecosystem Ready for NVIDIA RTX Spark

要点

  • NVIDIA 发布 RTX Spark 超级芯片，最高 128GB 统一内存、1 petaflop AI 算力
  • 搭载 RTX Spark 的笔记本将于 10 月 16 日上市，NVIDIA 与微软联合宣布
  • Nemotron 3.5 Bolt 74B 模型 10 月 15 日发布，专为本地 agent 打造

NVIDIA RTX Spark 是 PC 的新起点——一次重新发明，将游戏 PC、创作工作室和个人 AI 超级计算机的能力融合进一颗超级芯片。RTX Spark 最高配备 128GB 统一内存和 1 petaflop 的 AI 算力，为创作者、开发者和游戏玩家带来 NVIDIA RTX 与 CUDA 技术的完整技术栈，同时通过强大的本地 AI agent 开启个人计算的新范式。

上周，NVIDIA 与 Microsoft 宣布 RTX Spark 笔记本将于 10 月 16 日（周五）上市。在上市之前，NVIDIA 及其生态合作伙伴正陆续推出新的软件功能和性能优化，进一步拓展 RTX Spark 上本地 AI 的可能性。

在上市时提供的数千款应用、游戏和模型中，RTX Spark 新增及即将推出的更新包括：

  • 增强 RTX Spark 本地 agent 的新 agent 功能、模型和工具：
    • GitHub Copilot、Hermes、OpenClaw、Perplexity、Pi 和 WorkBuddy 等主流 agent 应用迎来更新，简化了在 RTX Spark 上的设置，通过 OpenShell 和 Microsoft Execution Containers（MXC）提升安全性，并支持本地与云端 AI 的混合路由。
    • 专为 RTX Spark 上的 agentic AI 打造的 NVIDIA Nemotron 3.5 Bolt 74B 模型将于 10 月 15 日（周四）发布。
    • NVIDIA PAIR 结束 beta 测试，并新增对 llama.cpp 的支持。
  • 为 RTX Spark 优化的主流创作应用：
    • Adobe 旗下主流应用即将迎来最高 2 倍的性能提升。NVIDIA 与 Adobe 合作，为 Photoshop 重新构建了 GPU 加速合成能力，并为 Premiere 重新构建了播放、渲染、特效等能力。
    • NVIDIA Broadcast 2.3 版本为该应用带来全新的视频超分辨率、视频帧生成、离线文件处理以及 agent Model Context Protocol（MCP）控制功能。
    • NVIDIA RTX 视频帧生成和高动态范围（HDR）功能现已在 ComfyUI 中提供，可加速 AI 生成式视频工作流。
    • NVIDIA DLSS Ray Reconstruction 将于 11 月在 Blender 5.3 中提供，以提升视口中的交互体验。
  • 开发者工具现已为 RTX Spark 做好准备：
    • 主流开发者框架现已支持 RTX Spark，包括 PyTorch、Python 和 CUDA，以及所有 CUDA 库。
    • GitHub Copilot、Pi 及其他编码 agent 现已针对 RTX Spark 优化。
    • Llama.cpp 新增对决策模型的支持，并发布 Windows 应用。
  • RTX Spark 支持数百款主流游戏及反作弊，此外还有：
    • 速度提升 2 倍的 DLSS 5 AI 模型将于 10 月 16 日（周五）推出，DLSS 帧生成的全新 Performance Mode 现已通过 NVIDIA App beta 提供。
    • 用于 NVIDIA ACE AI 游戏角色的第三代小语言模型（SLM）Nemotron 3.5 Bolt E4B 4GB 将于 10 月 23 日（周五）发布。
    • 最新 RTX Remix 更新（包括对 DLSS 5 的支持）将于 10 月 23 日（周五）发布。

以全新应用、模型和工具推进本地 AI agent

AI 正在改变人们与 PC 交互的方式。今年 agent 的热度飙升，OpenClaw 和 Hermes 等项目登顶 GitHub 热门榜单。本地大语言模型（LLM）已跨过驱动 agent 所需的智能门槛，Qwen 3.8-Flash-Next 等模型已能比肩几个月前才发布的前沿云端模型。因此，本地 LLM 的下载量已达到去年全年的 5 倍。

从模型到 agent harness，从安全到工具，NVIDIA 正与本地 AI 生态紧密合作，让 RTX Spark 成为运行本地 agent 的理想硬件。

在 RTX Spark 上轻松使用本地 AI Agent

从 RTX Spark 首次开机起，用户就会看到“快速入门”界面，用于选择和安装自己的 agent 应用。

得益于 NVIDIA OpenShell 和 MXC，这些 agent 将配备全新的安全沙箱技术。MXC 提供操作系统级安全，而 OpenShell 让 agent 更易采用 MXC，并增加了凭据保护和安全监控等高级能力。Hermes Agent 将在本月底前集成细粒度的 OpenShell 控制与 MXC。OpenClaw 和 GitHub Copilot 现已支持 MXC。

安装 agent 后，在 GitHub Copilot、Hermes Agent、OpenClaw、Perplexity、Pi 和 WorkBuddy 中设置本地 AI 如今也变得无缝顺畅。这些应用会为 RTX Spark 推荐经过优化的本地模型和设置配置，并只需点击几下即可为用户完成全部设置。

许多用户希望两全其美——用本地模型免费迭代，用云端模型获得前沿智能。NVIDIA Switchyard 是一个开源模型路由库，能让 agent 在本地和云端 LLM 之间智能路由查询，使用户既能尽量减少云端用量，又能获得与完全在云端运行相近的结果。Hermes 将在 10 月晚些时候加入 Switchyard，而 Perplexity Computer 和 GitHub Copilot 等其他 agent 已集成各自的路由方案。

软件提供商通过易用的 MCP 库和命令行界面（CLI），让 agent 能轻松连接顶级 Windows 应用。NVIDIA 现在也已为其应用提供 MCP，包括 NVIDIA App、Broadcast、PAIR、Omniverse、RTX Remix，以及一个庞大的 CUDA-X Skills 库。

NVIDIA 还将于 10 月 16 日（周五）发布面向 RTX Spark 的 AI playbooks。用户可以设置自己的第一个 agent、打造 AI 幕僚长、配置系统用于开发，或设计一个创意助手。

认识 Nemotron 3.5 Bolt 74B：为 RTX Spark 上的本地 agent 而生

NVIDIA Nemotron 3.5 Bolt 74B-A9B 24GB 将于 10 月 15 日（周四）发布，这是一款专为在 RTX Spark 上运行本地 agent 而打造的新 LLM。

该模型是一个 74B 参数、9B 激活参数的混合专家（MoE）模型，通过 2-bit 量化并借助先进的量化感知训练技术压缩至 24GB，以保持质量。它旨在实现速度与智能之间的最佳平衡，比大多数流行的稠密模型更快，同时比大多数内存占用相近的流行 MoE 模型更聪明。

用户将能在发布时通过 llama.cpp、vLLM、Ollama、Unsloth 和 LM Studio 运行 Nemotron 3.5 Bolt 74B。它也可通过 Hermes 和 OpenClaw 等 agent 直接访问。

与其他 Nemotron 模型一样，Bolt 74B 完全开源——包括训练数据、权重和配方——因此开发者可以微调和定制自己的 agent。

完美的 PAIR

本地 AI 不必只在一台 PC 上运行。NVIDIA PAIR，一款个人 AI 路由器，今天正式结束测试，让用户更容易利用本地网络中兼容 PC 的总 AI 算力。这款免费开源软件工具能自动发现并连接设备、安装 AI 模型和推理引擎，并将 AI 工作负载分配到可用的系统上。

正式版新增了对 llama.cpp 的支持、可直接从 Hugging Face 下载模型、可自定义推理引擎设置以及 RTX Spark 支持，还带来了一系列推理和用户体验方面的改进。

PAIR 可在 Windows、Linux 和 macOS 上运行。开发者可以通过Github为这个开源项目做贡献——在 PAIR 首次发布仅一个月后，社区已经为该版本贡献了 10 多项功能和修复。

激发创造力

RTX Spark 为高级内容创作工作流带来 130 多款加速应用、用于快速视频和图像生成的 CUDA，以及 DLSS、NVENC 和 OptiX 等 RTX 技术——全部集成在一台轻薄笔记本电脑中，随时随地提供强劲性能。

Adobe 为 RTX Spark 加速创意应用

Adobe 正在为其行业领先的创意应用（包括 Photoshop、Premiere 和 Substance 3D）针对 RTX Spark 进行优化，在创意工作流中实现最高 2 倍的 AI、编辑、色彩和特效速度提升。

在 Photoshop 中，GPU 加速的合成让复杂图像编辑更快、更流畅，同时改进了移除工具和漏光等效果。Premiere 加速了高要求的视频编辑任务，包括播放、渲染、调色以及增强语音和对象蒙版等 AI 功能。与此同时，Substance 3D Painter 加快了纹理创建工作流，从烘焙高分辨率网格贴图到打开、保存和导出大型项目。

这些更新将分阶段推出，Photoshop 和 Premiere 中的 AI 功能优化现已进入测试阶段，Adobe Substance 3D 的更新也即将到来。选择加入测试版即可获取针对 RTX Spark 优化的版本。

最新 NVIDIA Broadcast 为直播和录制内容带来全新 AI 效果

现已可下载，NVIDIA Broadcast 2.3 在 RTX Spark 上原生运行，并新增了 RTX Video Super Resolution 和 Frame Generation AI 效果以及 Studio Voice 配置文件。

全新的离线文件处理器让创作者可以将 Broadcast 效果应用于预先录制的内容，许多效果还能以更高质量运行，因为无需维持实时性能。此次更新还引入了新的 MCP 服务器和技能，让本地 AI agent 可以直接通过 Broadcast 应用调整效果、更改设置和处理文件。

RTX Video 为 ComfyUI 带来帧生成和 HDR

ComfyUI 正在扩展其 RTX Video 工具，新增两个节点：RTX Video Frame Generation 和 RTX Video HDR。它还提供了导出 EXR 文件的能力，为创作者提供更多增强 AI 生成视频的方式。

RTX Video Frame Generation 可为 GeForce RTX 40 系列及更新款 GPU 提升视频帧率，带来更流畅的画面；RTX Video HDR 则可将标准动态范围（SDR）素材转换为 HDR，为调色提供更大灵活性。结合 RTX Video Super Resolution，这些工具让创作者能在单个 ComfyUI 工作流中完成视频的放大、增强与精修。

例如，创作者可以将 LTX 2.5 与 RTX Video Frame Generation 和 HDR 结合使用，把一段 1080p、30 帧每秒（fps）的 SDR 片段转换为更流畅的 60 fps HDR 视频，并导出为 EXR 文件，随时可用于调色。

Blender 新增 DLSS 4.5 Ray Reconstruction 支持

Blender 已发布其热门 3D 编辑器的测试版，新增对 RTX Spark 的兼容支持。下载 Blender 5.3 版本 即可体验。

下个月，Blender 还将加入对 DLSS Ray Reconstruction 的支持，实现视口中的实时更新，让美术师在浏览场景的同时实时预览效果。

借助 RTX Spark 完成编码、文本处理与部署

开发者正从编写代码转向指挥 AI agent。这一新的开发范式要求许多人将工作分散在笔记本电脑、云端 LLM 和云虚拟机之间，在其中进行测试和原型开发。

RTX Spark 让开发者能在一台机器上完成所有工作：运行全部工作负载和库、测试与原型开发，以及部署。如今他们可以直接在 Windows 中通过全新的 Windows Developer Config 实现这一点——该配置优化了开发者体验，并安装所有主流开发工具——也可以通过 Windows Subsystem for Linux，获取与发布到云端时相同的软件包。

开发者工具已为 RTX Spark 就绪

NVIDIA 已与 Microsoft 合作，确保开发者工具为 RTX Spark 做好准备。伴随 RTX Spark 的发布，社区也在推出：

  • 首个面向 Windows on Arm 的 PyTorch-CUDA 构建版本。
  • 首个在 Windows on Arm 上默认原生运行的 Python 构建版本，采用 Python 3.15。
  • 首个面向 Windows on Arm 的原生 Conda 安装程序，包含超过 2,000 个 Conda 软件包。
  • 得益于与生态系统的合作，排名前 15,000 的 Python wheel 中已有 97% 准备就绪。NVIDIA 将与社区紧密合作，让剩余 wheel 也尽快就绪。

如今开发工作大多由 agent 完成。NVIDIA Skills——一个开源 GitHub 仓库，教 agent 如何使用 NVIDIA CUDA-X 工具和库——让用户即使完全不了解 CUDA，也能开发出由 NVIDIA 技术加速的应用。

编码 agent 已为本地 AI 做好准备

除了 GitHub Copilot——全球数百万人使用的最热门编码 agent 之一——新增对 MXC 的支持外，它还在更新其模型路由器 HydraFusion，加入对本地模型的支持。这使开发者能利用本地硬件减少 token 消耗，同时接入前沿智能。

Microsoft 正在让 MAI 1.1 Coding Flash 等编程模型在本地可用，并将 llama.cpp 作为后端加入 Windows ML——扩展了支持的模型范围，并启用了最新的 NVIDIA 性能优化。

开始使用在 RTX Spark 发布时本地运行的 GitHub Copilot。

Llama.cpp 新增对决策模型的支持，并发布 Windows 应用

决策模型是 AI 开发领域的最新突破。它们让 AI agent 能够近乎即时地做出决策，无需冗长的推理循环。从对请求进行分类到选择下一步行动，它们决定接下来做什么的速度比传统 agent 快最多 200 倍。决策模型现已在 RTX Spark 和 GeForce RTX GPU 上的 llama.cpp 和 Unsloth 中得到支持。

Llama.cpp 今天还发布了 Llama Windows，这是 llama.cpp 的 Windows 原生配套应用，提供易于使用的用户界面，可在本地下载和运行模型，无需进入命令行。这款应用与 llama.cpp 一样，针对 RTX Spark 进行了优化。可在 Hugging Face 博客上了解更多。

游戏开玩：RTX Spark 携数百款热门游戏和 DLSS 5 发布

RTX Spark 已为游戏做好准备，10 月 16 日星期五笔记本电脑上市时将有数百款热门游戏可用，包括 CONTROL Resonant、Cyberpunk 2077、Fortnite、Gears of War: E-Day、Genshin Impact、Hogwarts Legacy、Honkai: Star Rail、Marvel Rivals、NARAKA: BLADEPOINT、NBA 2K27、World of Warcraft 以及更多游戏。

NVIDIA 致力于将完整的 RTX 技术栈带到新平台，包括 DLSS、Reflex、Remix、G-SYNC 和光线追踪，同时与游戏开发者合作，为热门多人游戏启用反作弊支持。了解更多关于 RTX Spark 游戏体验的信息。

DLSS 5 将神经渲染带到 RTX Spark

搭载 3D-Guided Neural Rendering 的 NVIDIA DLSS 5 也将在 RTX Spark 发售当天登陆该平台。这项技术利用 AI 以逼真的细节增强光照和材质，让游戏世界和角色更加真实，同时保留开发者的艺术构想。全新且速度提升 2 倍的 DLSS 5 AI 模型将于 10 月 16 日星期五在 NBA 2K27 中首次亮相，可将帧率提升最多 1.4 倍。更快的模型还将从 11 月 5 日星期四起为 Hogwarts Legacy 中的 DLSS 5 提供支持，并于 11 月下旬支持 Where Winds Meet。

DLSS 5 也将于 10 月 23 日星期五登陆 NVIDIA RTX Remix，让 mod 作者能为经典角色和环境添加更出色的材质、光照和阴影，正如 mod 作者 Sparkles/Kim2091 在其开发中的项目《辐射 4 RTX》中所展示的那样。

在 GeForce.com 上阅读更多关于RTX Spark 上的 DLSS 5的内容。

游戏 agent 在 RTX Spark 上本地运行

Nemotron 3.5 Bolt E4B 4GB 是 NVIDIA ACE 的第三代 SLM，ACE 是一套用于构建游戏内 AI agent 的技术套件，可带来下一代游戏体验。第一代模型今年早些时候在《PUBG》中开启公开测试，让玩家能与 AI 队友组队；而更高效的第二代模型则在科隆游戏展的《Aniimo》中预览，将普通生物变成能响应语音的伙伴。

Nemotron 3.5 Bolt E4B 将自然对话与多轮工具调用、指令遵循以及基于应用状态的 grounding 相结合，为快速的本地语音和设备助手、互动角色以及嵌入式界面提供支持。

该模型专为低内存占用和快速首 token 时间而设计，在实现响应迅速的本地体验的同时，为应用和其他 AI 模型留出余量。其全新的对话模式有助于让回复简洁且适合语音播报，开发者还可以按需开启或关闭推理。

从 10 月 23 日星期五开始，可在 SkyrimNET 中试用第三代 Nemotron 3.5 Bolt E4B 4GB。SkyrimNET 是 MinLL 为《上古卷轴 5：天际》打造的 AI 非玩家角色（NPC）mod 平台。SkyrimNET 将每个 NPC 转变为无脚本的互动角色，配备个人记忆、语音和自主性，可进行动态对话并即时生成情境感知任务。

SkyrimNET 现已兼容 RTX Spark，支持跨多个模型的云端和本地推理，最新的 Nemotron 模型可提供一流的性能，实现高效快速的游戏内互动。可在GitHub上下载该版本。

加速 RTX Remix 中的 mod 工作流

随着 AI agent 持续帮助 mod 作者让他们喜爱的经典游戏兼容RTX Remix 渲染器，NVIDIA 正通过对其 AI 驱动的纹理生成工作流进行重大改造来简化资产更新。作为 Remix 1.6 的一部分于 10 月 23 日星期五推出，ComfyUI 版本 2 用侧边栏中专门的 AI 工具布局取代了复杂的 REST 应用程序编程接口（API）节点连接。

此次更新让 mod 作者和美术师无需任何 API 设置即可在 RTX Remix 中原生生成基于物理的渲染材质。新的批处理功能让用户能轻松从单张纹理实验扩展到完整的 mod 项目，而直观的预设系统则让非技术创作者无需接触节点图即可调整关键设置。
