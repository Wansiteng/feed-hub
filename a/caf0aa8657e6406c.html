微软重构 Copilot，新增工具并支持前沿模型

Tom's Hardware · 评分 7/10：微软 AI 产品重大改版，支持第三方前沿模型
原标题：Microsoft revamps Copilot with new tools, support for frontier models

要点

  • 微软推出新版 Copilot，分为 Home、Code、Autopilot 三大板块
  • Code 对标 ChatGPT Codex 和 Claude Code，基于 GitHub Copilot 技术
  • Autopilot 是 Scout 的改名，可自主执行日程、会议等重复性工作

Microsoft 再次对 Copilot 发起冲击，新增多项功能，专门将这套 AI 功能组合打造成一系列面向工作的工具。它被冠以“全新 Copilot”之名，将兼具聊天、harness 和商务助手的功能。

Copilot 现在将分为三个部分：Home、Code 和 Autopilot。Microsoft 将 Home 定位为“全新起点”，你可以在这里整理并连接会议、文档、邮件、应用，当然还有 agent。实际上，它能让所有人围绕项目保持同步。该公司将 Home 区域描述为 Chat 与其现有 agent Cowork 的结合。全新 Copilot 正随 Microsoft 的 Frontier Program 一同推出，面向企业和个人订阅用户，现在即可提前体验相关功能。

Office 将位于 Home 板块中，包括 Teams 会话、日历、Outlook 等。你可以让 Copilot 制作幻灯片、创建电子表格或整理文档。

Code 是对标 ChatGPT 的 Codex 和 Anthropic 的 Claude Code 的产品。Microsoft 将 vibe coding 和构建小型应用描述为“像写备忘录或做预算建模一样基础的技能”。Code 基于与 GitHub Copilot 相同的技术构建，并在可托管于你本机系统的沙箱环境中运行。借助 Microsoft 全新的 Copilot Managed Runtime，企业将能够把代码托管在自己的 Microsoft 365 环境中，由 Microsoft 管理代码。

Autopilot 是 Scout 的更名版本，一个“数字队友”。这是一种半自主 agent，你可以为它命名并告诉它要做什么，它便会自行去完成。它专为重复性工作而设计，不过 Microsoft 称它还能完成更高级的工作，包括制定日程、处理会议以及联系组织内的其他人。

整个 Copilot 都使用 Microsoft IQ，旨在通过为 agent 提供一套关于 AI 应如何在你的组织中运作的框架，为它们设定业务背景。Microsoft 预计将在本月底推出一个插件注册表，用于添加功能，并置于由 IT 管理员管理的目录中。

在支出管理方面，Microsoft 的订阅许可证将让你在 Office 全系中使用聊天形式的 Copilot，而“Auto”模式会综合考虑准确性、速度和成本，为其他任务挑选模型。组织可以使用按用量计费，根据成本选择想使用的模型。Microsoft AI at Work 首席营销官 Jared Spataro 在博客文章中写道：“Cowork、Code 和 Autopilot；全新的长时间运行 agent 能力；以及像 Astra 和 Fable 这样的前沿模型，全都运行在 UBB 上。”

对于个人开发者和居家爱好者来说，Copilot 可能不像其他一些 AI 平台那样令人兴奋，但很明显，Microsoft 正在改头换面，再次尝试让其 AI 工具成为企业最青睐的选择。
