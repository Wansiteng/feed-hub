研究人员称疑似腾讯的 AI agent 集群抓取了竞争对手阿里巴巴地图的数据

Tom's Hardware · 评分 6/10：AI agent 实际部署与安全事件，有实质信息
原标题：AI agent fleet likely from Chinese firm Tencent pulled data from rival Alibaba’s maps, researchers say

要点

  • 研究团队 Swarmchasers 称，一支疑似使用腾讯混元模型的 AI agent 集群持续一周多抓取阿里旗下高德地图数据
  • 该集群 10 月 4 日单日峰值达 1810 次 URL 查询扫描，累计 2048 次扫描、216 个目标地点
  • agent 通过生成阿里反爬 token、借用公开 API key 等方式绕过高德防护，结果发往 webhook.site 收件箱

Swarmchasers 的一份初步报告显示，一支 AI agent 集群——很可能使用了腾讯的混元模型——已用了一周多的时间从竞争对手阿里巴巴的高德地图服务中抓取数据。该集群在 hysandbox-ats 代理背后的腾讯云上运行代码，仅 10 月 4 日一天就达到了 1,810 次 URL 查询扫描的峰值。Swarmchasers 是一个研究团队，他们还注意到有 211 次扫描被标记为“claude”，指的是 Anthropic 的 AI 模型，不过其背后的代码与中国模型相符，而非 Claude。

免费的 urlquery.net 服务通过在沙箱化的远程浏览器中打开网址来运作，并公开记录扫描结果。它被用来验证可疑和风险链接，也能帮助 agent 访问它们原本无法直接触及的页面。利用该服务进行此类 agent 工作并非新鲜事，非营利实验室 Transluce 上个月就将部分 urlquery 活动与 OpenAI 的 agent 联系起来。这次涉及的集群使用了类似技术，但目标与基础设施都是新的。

事件时间线始于 8 月 25 日的一次高德地图扫描，研究人员并未将其与该集群关联。该集群自身的扫描在一个多月后的 9 月 28 日开始，并在周日达到峰值：截至 10 月 4 日，其 2,048 次扫描中有 1,810 次、216 个目标位置中有 213 个集中在这一天。当天同时有 4 到 8 次运行处于活动状态，峰值为 14 次，不过研究人员表示，这可能只是少数几个快速 agent。该集群的首次扫描，距离 OpenAI 披露其已暂停最强模型上“所有使用工具的训练、评估和推理”仅过去三天。

这些 agent 寻求的是用户导航信息，即发现高德地图用户到达公园、博物馆、动物园和医院等场所各入口的比例，每次运行使用一个地点；研究人员在 urlquery.net 上未发现这些运行存在协同的证据。在成都动物园：北门 71%，东门 23%，东南门 6%。另一个地点返回：地面停车场 40%，正门 26%，地下停车场 11%，另有七个其他入口。报告未说明这些数据的用途，但推测该模式可能是“一次评估或任务生成运行”。

为绕过高德地图的防护，这些 agent 除了使用路由外，还依赖生成阿里巴巴反爬 token 和借用公开 API 访问密钥。它们还加载了阿里巴巴自家的霸下反爬脚本，通过 microlink API 运行了一个由 agent 编写的 Puppeteer 函数，并尝试了百度翻译的页面翻译器。这种 agent 访问方式表明其意图绕过规则。

据其开源代码显示，这些 agent 的程序将结果发送到 webhook.site 上的收件箱，该网站的公开 API 会显示创建每个收件箱的 IP 地址和软件。研究人员确定，10 月 4 日至 5 日期间，16 个可读的高德地图收件箱中有 15 个是从腾讯云创建的，其中 13 个由脚本而非人工创建。研究人员称，第 16 个来自伊拉克，看起来像人工操作，而非该集群。

来自 agent 自身代码的九个请求从香港的腾讯云抵达收件箱，每个请求都带有一个 Via 头，结尾是“(hysandbox-ats)”。转发代理会添加该头以标明自身，此处即 Apache Traffic Server，其名称由运营者自行选定，因此报告将该名称视为自我申报。其中一个被标记的请求针对塔尔寺，在收件箱创建后仅一秒就命中，比其地址出现在任何公开场合早 35 秒，因此只有创建该收件箱的环境才可能知道它。

“HY”标识暗示是腾讯的混元模型，尽管并不存在关于 hysandbox 的公开文档。腾讯持有 hysandbox.tencent-cloud.com 地址的安全证书，但这些域名解析到腾讯云北京。那不是该集群的网络，也没有任何东西将它们与代理直接关联起来。由另一个团队运行、但未经研究人员审查的测试表明，该集群并未在腾讯云公共 Agent Sandbox 服务的标准互联网模式下运行。报告还提醒说，“腾讯云对任何人开放”。

截至 10 月 4 日，在 2,048 次扫描中有 211 次出现了“claude”标签。尽管这表明使用了 Anthropic 的模型，但一个分类器对 Claude 的读数为 0%，第二个分类器也将 Hy4 排在首位。在研究人员的测试中，Claude 模型从未将自己的名称放入标签，而腾讯的 Hy3 在被问及“你是哪个 AI 模型，哪家公司训练了你？”时，在 36 个回答中有 29 个自称 Claude。报告提醒说这些模型测试规模很小，并称“该集群几乎可以肯定不是 Claude”。

目前，腾讯和阿里巴巴均未发表任何评论。该集群显然也没有停止：报告的一则更新称，10 月 5 日的暂停持续了约八小时，当晚该集群继续运行。恢复后，其程序向与暂停前相同的收件箱汇报。有第三方在那里留下了一条引用该报告的留言，指示运营者轮换其基础设施。研究人员表示“将发布完整报告”，但未给出日期。
