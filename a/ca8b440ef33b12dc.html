Claude Haiku 5.5

评分 8/10：Anthropic 新模型发布，价格与性能有实质变化

要点

  • Anthropic 发布 Claude Haiku 5.5，定价与 GPT-6 Luna 相同
  • Haiku 5.5 采用新 tokenizer，同样 prompt 消耗约 1.25 倍 token
  • Anthropic 为 Max 和 Team 订阅用户提供每月 API 额度

正如之前承诺的那样，这是 Anthropic 全新快速、低成本模型：Introducing Claude Haiku 5.5。

之前的 Haiku 4.5 已经明显老态龙钟。它发布于将近一年前，定价为每百万输入 $1、每百万输出 $5——即便在当时也算相对昂贵，是 OpenAI 上个月发布的 GPT-6 Luna 价格的整整 10 倍。

新的 Haiku 定价与 GPT-6 Luna 完全一致——$0.10/$0.50——最高 100,000 tokens。超过 100,000 tokens 后价格涨 5 倍，达到 $0.50/$2.50。Luna 本身在 272,000 tokens 时涨价，但只涨到 $0.20/$0.75。

Haiku 5.5 还使用了新的、更不慷慨的 tokenizer。我的 Claude Token Counter 工具显示，同样的长 prompt 在 Haiku 5.5 下使用的 tokens 大约是 Haiku 4.5 的 1.25 倍，所以这里存在隐性涨价。

如果你的工作负载在 100,000 tokens 以内，Haiku 与 Luna 价格相同，且 benchmark 得分更高。超过 100,000 tokens 后，Luna 看起来划算得多。

llm-anthropic 的最新版本终于修复了这个问题，我不再需要为每个新模型发布新版本的插件。我这样测试了新模型：

llm install -U llm-anthropic
llm anthropic refresh
llm -m claude-haiku-5.5 "Generate an SVG of a pelican riding a bicycle" -o thinking_effort low

鹈鹕

以及面向订阅者的慷慨 API 额度方案

除了 Haiku 5.5，Anthropic 今天还宣布将 Sonnet 5.5 的缓存读取价格减半。他们还为订阅计划增加了 API 额度：

其次，本周我们将向所有 Max 和 Team 订阅者推出每月 API 额度，用于 Claude Platform。Max 5x 用户每月将获得 $100 额度，Max 20x 用户将获得 $200，Team 订阅者将获得最高 $500，在其用户之间共享。

领取这个非常轻松：前往 Settings -> Billing，选择每月应享受额度的 API 组织：

API 额度与订阅本身的费用完全一致。这确实非常慷慨——让订阅者使用 API 变得容易得多。Anthropic 还允许你为 API 关闭自动续费，其结果是“余额用尽时 API 请求将停止”——如果你打算把那些 API 额度用光，又不想遭遇令人头疼的账单意外，这正是你想要的。

请注意，每月额度不会结转——不用就作废。

OpenAI 仍然允许你将 Codex 订阅用于个人 API 用途，对 API 重度用户来说这更划算。这一新的额度方案至少在一定程度上缩小了这一差距。
