原标题：Redesigned MacBook Pro with OLED to feature ‘significantly lighter’ design: report

要点

  • 新机将首次配备触控屏和 Tandem OLED 屏幕
  • 新 MacBook Pro 采用重新设计的内部结构，重量显著减轻

Apple’s major MacBook Pro overhaul is just around the corner, and should debut within a month or so. It’ll be the first touchscreen MacBook, as well as the first with Tandem OLED. Beyond that, though, the new MacBooks should be ‘significantly’ lighter than their predecessors, according to the latest issue of the Power On newsletter.

苹果对 MacBook Pro 的重大改款即将到来，预计将在一个月左右内亮相。这将是首款触屏 MacBook，也是首款采用 Tandem OLED 的机型。不过，根据最新一期 Power On 通讯，新款 MacBook 还将比前代“显著”更轻。

The newsletter reiterates that the new MacBook Pro should debut ‘by next month,’ so we should see these new machines before the end of November. These machines should offer the current M5 Pro and M5 Max chips, as Apple has opted to skip the higher-end part of the M6 family in favor of accelerating the M7 launch.

该通讯重申，新款 MacBook Pro 应会“在下个月前”亮相，因此我们有望在 11 月底之前见到这些新机器。这些机器预计将搭载当前的 M5 Pro 和 M5 Max 芯片，因为苹果选择跳过 M6 系列的高端型号，以加速 M7 的发布。

New MacBook Pro to be much lighter

新款 MacBook Pro 将大幅减轻重量

Despite the fact that these MacBooks have been rumored for quite some time, we haven’t really known too much about them besides specs on paper: OLED, touch, Dynamic Island, and so on. In the past, reports have described the computer as thinner, but we haven’t really had much of a visual. We still don’t, but we do have one major new detail on what this machine will feel like:

尽管这些 MacBook 的传闻已流传多时，但除了纸面规格——OLED、触控、灵动岛等等——我们对其了解其实并不多。过去有报道称这款电脑更薄，但我们一直没有太多直观感受。现在依然如此，不过我们得到了一个关于这款机器手感的重要新细节：

The new MacBook Pros are lighter — significantly lighter. Apple has reengineered the machine’s interior miniaturizing parts and rearranging components to make the computer much easier to carry. The current 16-inch MacBook Pro weighs as much as 4.8 pounds, compared with 3.3 pounds for the 15-inch MacBook Air, so any meaningful reduction would be immediately noticeable.

新款 MacBook Pro 更轻了——显著更轻。苹果重新设计了机器内部，将部件小型化并重新排列组件，使电脑更便于携带。当前的 16 英寸 MacBook Pro 重达 4.8 磅，而 15 英寸 MacBook Air 为 3.3 磅，因此任何有意义的减重都会立刻被察觉。

Bloomberg’s Mark Gurman doesn’t specify exactly how much lighter it will be, but if you’re someone who uses a current-generation MacBook Pro, especially the 16-inch, you might find that it’s heavier than you’d like it to be. Apple is reportedly working to improve on that.

彭博社的马克·古尔曼并未具体说明会轻多少，但如果你正在使用当前一代 MacBook Pro，尤其是 16 英寸机型，你可能会觉得它比你希望的更重。据报道，苹果正致力于改善这一点。

Beyond that, Gurman also mentions that there will be some changes in macOS Golden Gate to support touch and the Dynamic Island, alongside the debut of macOS 27.2.

除此之外，古尔曼还提到，macOS Golden Gate 将有一些变化以支持触控和灵动岛，同时 macOS 27.2 也将首次亮相。
