Ollama v0.40.0

Ollama Releases · 评分 9/10：Apple Silicon 默认改用 MLX 运行模型，直接影响本地推理
原标题：v0.40.0

要点

  • Ollama v0.40.0 发布，Apple Silicon 上默认用 MLX 运行模型
  • MLX runner 支持的模型架构将在 Apple Silicon 设备上默认启用
  • RC 阶段将继续测试并启用更多模型

变更内容

模型在 Apple Silicon 上默认通过 MLX 运行

在此版本中，MLX runner 支持的模型架构将在 Apple Silicon 设备上默认运行。

ollama pull qwen3.8
ollama run qwen3.8

在 RC 期间，我们将测试并启用更多模型。
