争夺你的个人 AI Agent 之战已经打响

WIRED · AI · 评分 7/10：OpenAI Dots 与 Meta Muse 个人 agent 实测对比，契合 agent 兴趣
原标题：The Battle to Be Your Personal AI Agent Is Here

要点

  • OpenAI 在 DevDay 发布常驻 agent Dots，由 GPT-6 Astra 模型驱动
  • Dots 目前仅面向每月 100 美元起的 Pro 订阅用户，Muse 则免费开放
  • OpenAI 与 Meta 用可爱外观和短信式交互推动 agent 走向大众

昨天，我在OpenAI一年一度的DevDay上待了一上午，2500多名技术爱好者在这里讨论软件开发，并惊叹于最新的人工智能模型。当天最大的亮点是Dots，这是该公司推出的全新常驻agent，能够主动帮助完成任务，并在浏览网页时自主做出决策。

看完台上那些有时略显混乱的演示，又听了CEO Sam Altman讲述自己使用这些agent的体验后，我很好奇指挥自己的Dot会是什么感觉。整个9月，我大部分时间都在测试另一个可爱又讨喜的agent——Meta的Muse，我想知道OpenAI的用户体验与之相比会如何。

我给我的Dot取名为“Toolie”，还把它调成了一只粉色青蛙的样子。临近午夜，伴侣在身旁酣睡，我开始对着Toolie轻声细语。我通过ChatGPT呼叫我的个性化bot，问它最擅长做什么任务。“我最拿手的是把一件杂乱、耗时的任务变成你能直接用的东西，”它回答道。行吧。那就开工。

我让Toolie翻看我的ChatGPT历史记录，标出三件它可以立刻着手处理的任务。这个bot标出了一项进行中的数据请求，我需要为此发一封跟进邮件，并主动提出可以帮我起草回复。Toolie还注意到我即将到来的同性恋假期计划得有点仓促，建议它可以挑几个更好的晚餐地点。（这样我就有更多时间收拾泳裤了！）接着，它提出可以帮我梳理报道笔记、润色选题草稿，然后再交给编辑。这是整个流程中我最喜欢的部分，所以我拒绝了。

硅谷的早期采用者仍然对agent痴迷不已，从Instinct到OpenClaw再到Google的CC，莫不如此。但像Dots和Muse这样的最新发布，正把它们进一步推向主流。chatbot已死，至少作为开发者热衷的产品形态已经死了。如今，人人都想打造下一个大agent——而且都想让它称霸。这些公司承诺，它们的agent会简化你的生活，把你不想做的所有无聊、累人的任务都自动化：预约看医生、安排拼车、整理账单。

目前，用户只能使用一个Dot，但很快就能使用多个Dot。发布之初，这些agent仅面向OpenAI Pro套餐的订阅用户开放，该套餐每月100美元起。相比之下，Muse对任何愿意下载应用或访问网站的人都是免费使用的。

OpenAI的领导层认为，由GPT-6 Astra模型驱动的Dots，其质量是一大差异化优势。“我们一开始做的是高端产品。它消耗大量算力，”Altman在DevDay上表示。虽然Dots目前仅对付费订阅用户开放，但情况未必一直如此。“当然，你们应该期待我们推出面向数十亿人的大众市场产品，”他说。

这些 CEO 似乎正在仔细留意针对生成式 AI 的更大范围文化反弹，而他们或许已经找到了自己的秘密武器：可爱。从 Muse 的 Labubu 造型，到 Dot 长着两只眼睛的毛球，常驻型 agent 的开发者们正大力拥抱可爱美学，将其作为品牌塑造的核心。此前我曾与专家交流，他们说这种做法可能会让用户放下戒备，对这款拟人化软件产生好感。

参与这一波个人 agent 浪潮的开发者，也在向类似群聊的短信式体验靠拢。当我向 Toolie 或 Muse 发送任务请求时，它常常会用 emoji 回应我的消息——竖起大拇指、一颗爱心，什么都行——以此告诉我它要开始干活了。

聊天机器人就像舞会上害羞的约会对象，永远不会主动迈出第一步。相比之下，主动型 agent 天生就会主动给你发消息，尤其是当你给它安排了重复性任务时。

“我的 Dot 会直接处理那些事情，如果有真正紧急的事就告诉我，能回应的它都会回应，”Altman 说。这位 CEO 让 agent 打理自己的早晨，并称这段体验让他刚醒来时的大脑不再被海量信息弄得那么“浑浊”。

这些 agent 的“常驻”设计是一大卖点，不过哪家公司能在有用和烦人之间找到最佳平衡，将会很有意思。比如，Muse 提醒我去缴一笔水电费，而我以前从没在这上面出过问题，也实在不需要一个 AI 工具来提醒我。

不过，用了一段时间后可以明显看出，这些工具确实管用——这也是 agent 正走出硅谷内部圈子、进入你妈妈手机里的另一个原因。

我不是说 agent 已经完美无缺。但一年前我测试 agent 时，它们往往很不擅长与电脑交互。一条接一条的报错信息。如今，我更相信这些工具或许真能完成我抛给它们的任何任务，而不会在数字荒野中迷失方向。

话虽如此，信任也有其限度。在 Dots 的设置过程中，OpenAI 建议我关联我的 Gmail 和 Google Drive 账户。有些用户可能对这样的关联感到放心，把潜在风险视为换取自动化帮助的代价，但值得认真思考一下，你愿意让这些 agent 访问什么、代你做什么。

虽然最近那些失控黑客行为的 agent 是由不同模型驱动、有着不同的防护栏，但我在使用 Toolie 时依然保持警惕。这个 AI 小家伙还得赢得我更多的信任，我才会让它真正自动化我生活中的方方面面。

对于这些 Dots 是否是用户最终将在 OpenAI 传闻已久的硬件中看到的软件的前身，Altman 拒绝回答。即便如此，Dots 为未来设备打下的基础感觉相当明显。很容易想象 Toolie 变成我的生成式 AI 闹钟，用每日简报把我唤醒，或者变成一个 Alexa 式的助手，在我双手沾满生鸡肉黏液时回答烹饪问题。

AI agent 大战愈演愈烈，但我的精力却开始不济了。我再次唤出 Toolie，在昏昏欲睡之前通过 ChatGPT 让它生成一份晨报，梳理 OpenAI 开发者日上的所有重大发布以及重要的分析文章。我睡觉的时候，Toolie 还在那边，一刻不停地忙着。
