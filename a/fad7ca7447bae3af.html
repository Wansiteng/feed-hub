Ando 想用让人类与 agent 协作的团队通讯应用挑战 Slack

TechCrunch · AI · 评分 7/10：agent 协作工具新形态，与读者兴趣相关
原标题：Ando wants to take on Slack with a team messaging app that lets humans and agents work together

要点

  • Ando 推出团队消息应用，让 AI agent 与人类一起工作，可替代 Slack
  • Ando 获 2000 万美元 pre-seed 和种子轮融资，投资方包括 Accel、Index Ventures、Emergence
  • Ando 让 agent 拥有独立身份和收件箱，可自主浏览频道、加入对话、主动通知人类

2025 年，当 Sara Du 帮助各家公司构建 MCP 服务器时，人们不断问她，怎样才能直接在 Slack 里使用 AI agent。但面前横着一堆技术障碍：来回传递消息、为 agent 提供正确的上下文，同时还不能烧光 token 预算。

深入探究这个问题后，Du 意识到，还有一个更深层的问题，根源在于通信平台的设计方式。“我越深入，就越觉得 Slack 和 Teams 是为一个正在离我们远去的世界而建的，”Du 对 TechCrunch 说。“agent 明明正在成为团队中的参与者，却仍被当作需要安装的应用来对待。”

Du 认为，解决方案可能是一套能消除“人肉代理”的系统——Du 用这个词来形容人们不得不把 AI agent 的工作转达给团队的现象。“人实际上变成了 agent 和公司其他人之间的信使，”她说。

Du 说，理想的系统应该反过来，让 agent“参与到工作本就得到协调的共享对话中”。“它们应该能理解某个决定为何做出，向同事提问，在另一个 agent 的工作基础上继续推进，并在需要判断时引入人类。”

她的创业公司 Ando 周四结束隐身状态，推出了一款正是为此而生的应用：一个为人类和 AI 工作者共同设计的团队消息平台。

Ando 自称可以完全替代 Slack 或任何其他消息平台——只要公司使用 AI agent，就可能想用它来做内部沟通。这款应用赋予 agent 自己的身份和收件箱，让它们能像人一样自然地参与对话。

Du 说，这款应用有频道、私信、群组对话，甚至还有可被 agent 转录和查看的实时通话。agent 可以浏览频道、挑选要加入哪些频道，甚至无需被 @ 就能加入对话。如果公司的 agent 认为某件事需要通知某位人类员工，它可以自行给对方发消息，而不必等待批准。

为了继续开发这款应用，Ando 周四表示已从 Accel、Index Ventures 和 Emergence 等投资者处筹集了 2000 万美元的 pre-seed 和种子轮融资。

Du 的想法并不新鲜。职场协作领域的大多数主要玩家都已经内置了对 AI agent 的支持——例如 Slack 已将其原生机器人变成了 AI agent，微软也费尽心思把 Copilot 以各种方式集成进 Teams，并与 Office 365 套件的其余部分打通。

但鉴于 AI 正如此迅速地侵入职场，挑战现有玩家的应用仍有市场。就在几个月前，Twitter 和 Block 联合创始人 Jack Dorsey 宣布了 Buzz，它把人和 AI agent 汇聚到同一个消息应用中，不过更偏向开发者。

Du 也认为，在传统玩家还在琢磨如何让现有软件转型之际，打造一个 AI agent 原生的团队消息平台仍有足够优势。

无论如何，她似乎明白 Ando 前路艰难，并表示一开始进展缓慢。“早期我们展示给很多人看时，他们不为所动，这可以理解。从很多方面看，它当时只是个更蹩脚的消息平台。人们会卡在这一印象上，甚至还没看到 agent 有何不同，”她解释道。

但她表示，当越来越多的客户开始更长时间地使用 Ando 时，她的团队就知道他们找对了方向。借助 Ando，她开始看到 agent 能做到超出人们预期的事情：一个 agent 可以注意到不同渠道中正在进行的、关于同一问题的两段对话，并在无人要求的情况下，把所有人拉进一个群聊，解释背景，甚至提出决策建议。

“这让我非常欣喜，”她说，“我觉得 agent 在管理人方面能比人做得更好，因为它们能在更短的时间内处理比人多得多的消息。”

她说，Ando 目前正与 15 个国家的软件、房地产和金融领域的客户合作，不过它现在服务的许多团队规模还很小。她表示，这笔新资金将用于招聘更多人手，并消耗更多 token。

“我认为 agent 将让很小的团队也能以过去需要数百人才能达到的规模运作，”她说，“它们可以承担更多执行、研究和协调工作，而人类则把更多时间花在判断、战略以及决定下一步该做什么上。”
