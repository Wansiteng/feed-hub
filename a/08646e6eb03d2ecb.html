关注英伟达 RTX Spark 的最佳理由：一切都将跑在 Arm 上

The Verge · 评分 6/10：Arm PC 生态分析，芯片与硬件相关
原标题：The best reason to care about Nvidia’s RTX Spark: ‘everything’ will run on Arm

要点

  • 英伟达将于10月16日推出首批RTX Spark笔记本，搭载Arm芯片运行完整Windows 11
  • 英伟达称RTX Spark可运行所有应用和游戏，包括需要内核级反作弊的游戏
  • RTX Spark芯片实为一年前用于AI迷你主机的同款芯片，此前仅运行Linux

十四年前的这一月，微软发布了一款搭载英伟达芯片的 Windows PC，它后来成为现代历史上最惨烈的科技失败案例之一。初代 Microsoft Surface 在英伟达 Tegra 芯片上运行精简版 Windows，惨败到微软不得不减记 9 亿美元的库存。

问题在于，英伟达的 Arm 芯片无法运行现有的 Windows 应用。买家不得不抛弃自己的旧程序。

本周五，也就是 10 月 16 日，英伟达将凭借首批 RTX Spark 笔记本再次站上 Arm 架构 Windows PC 的核心位置。但该公司表示，这一次它们能运行一切。Adobe。Office。Blender。甚至连需要内核级反作弊的游戏也不在话下。

“你所有的应用、所有的游戏，一切都会在 Spark 上流畅运行，”英伟达产品高级总监 Justin Walker 上周对记者表示。

我敢打赌，大多数 Verge 读者不会揣着高达 7000 美元去入手一台未经检验、配备 128GB 内存的本地 AI 工作站。就算你有这笔钱，我也不确定你会喜欢一台轻薄笔记本把 GPU 拉满、只为在本地产出“免费”token 所带来的种种取舍。正如 Tom 所指出的，它比云端 AI 慢得多。

但很难不为一个未来感到兴奋——那时 Arm 芯片能胜任我们对 Windows PC 所期待的其他一切。

摄影：Sean Hollister / The Verge

英伟达上周在旧金山举办了一场 Editor's Day，力图让人相信 RTX Spark 笔记本就是那个“全能选手”。游戏玩家、创作者、开发者和 AI 重度用户各自都有一套专门的幻灯片，用来讲解这颗芯片的优势。

活动最后，英伟达发放了供评测的笔记本，我现在正用其中一台写这篇报道。用了几天后，我发现它大体上与一台传统 Windows 机器难以区分，不过等完整禁运明天解除后，我们会带来更多关于早期优缺点和怪癖的看法。

RTX Spark“超级芯片”并非全新的硅片——它正是该公司整整一年前用在面向 AI 开发者的迷你台式机里的同一颗芯片。但那些机器运行的是 Linux；这一台运行完整的 Windows 11，并借助微软的 Prism 模拟器让旧款 Windows 应用和游戏在 Arm 芯片上运行。

英伟达并非第一家押注将 PC 软件扩展到原本并非为其设计的平台的公司。从 2020 年开始，Apple 借助其 Rosetta 2 模拟器，将所有电脑从 Intel x86 芯片迁移到自家基于 Arm 的芯片。2022 年，Valve 的 SteamOS 在 Linux 社区帮助下证明了 Windows 游戏在 Linux 上的潜力，随后又证明了在 Arm 上的潜力。到了 2024 年，Prism 模拟器首次亮相，当时 Qualcomm 推出了首批广受好评的 Windows on Arm 设备，包括微软 Surface Laptop 第 7 版。

摄影：Sean Hollister / The Verge

但在 AI 和游戏方面，英伟达想要超越它们所有。

尽管 Qualcomm 最初声称大多数游戏应该“直接就能玩”在搭载骁龙芯片的 Windows 笔记本上，但现实却令人大跌眼镜。有些游戏完全报错，有些出现卡顿，而且 Qualcomm 的 Snapdragon X Elite 芯片一开始瞄准的就是相对低端的游戏。许多全球最热门的多人在线游戏，比如《堡垒之夜》，都无法在 Qualcomm 或 SteamOS 设备上运行，因为它们的反作弊软件分别与 Arm 和 Linux 不兼容。

不过，英伟达的 RTX Spark 在图形性能上远超 Steam Deck 或 Qualcomm Snapdragon X Elite，在我们的早期测试中更接近 RTX 5060 这样的中端独立笔记本 GPU，而且英伟达表示正在与一长串游戏公司合作，以支持市面上几乎所有的反作弊方案。

英伟达表示，它已经支持《堡垒之夜》、Roblox、《Rust》、《彩虹六号：围攻》和《冒险岛》中使用的各种反作弊软件——这些游戏此前都与 Valve 的 SteamOS 不兼容——英伟达还表示，保护《使命召唤》、《绝地求生》、《英雄联盟》、《无畏契约》、《Apex 英雄》、《战地》以及许多 EA Sports 游戏的各种反作弊软件，都将在之后正式登陆 RTX Spark。

现实情况是，一些“受 CPU 限制”的游戏会运行得更慢，因为微软的 Prism 必须实时将其 x86 指令转换为 Arm 指令，从而给一切操作增加延迟。我的同事 Tom Warren 无论怎么尝试，都无法让《地平线：零之曙光 重制版》跑到 30fps 以上，很可能是因为这款游戏相当依赖 CPU。而当我的同事 Antonio Di Benedetto 尝试《刺客信条：影》时，也无法突破 30fps——一台 MacBook Pro M5 Max 运行该游戏的速度是它的两倍。

摄影：Sean Hollister / The Verge

但大多数游戏仍然受限于图形性能而非 CPU——而 RTX Spark 内置的英伟达 Blackwell GPU 与传统笔记本中的 Blackwell 完全相同，无需转换。到目前为止，我们在《赛博朋克 2077》等游戏中看到了流畅的 1080p 性能，而且我们发现，如果你愿意接受低或中等画质设置并大量使用 DLSS 超分，还可以将其扩展到这些笔记本原生的 1800p 或 2180p 分辨率。

（官方说法是，英伟达声称你可以在 1440p 分辨率下以 135fps 畅玩《007 First Light》《赛博朋克》《战争机器：E-Day》《毁灭战士：黑暗时代》《永劫无间》和《Pragmata》，但这是在开启 DLSS 以及 3 倍帧生成的情况下实现的，也就是说每生成一个真实帧就伴随两个“假”帧。这些结果可能还使用了英伟达速度更快、但画质有所降低的新帧生成模型。）

摄影：Sean Hollister / The Verge

在正常年份，当英伟达还是一家正常公司的时候，RTX Spark 笔记本能“正常工作”就已经足够了。但如今英伟达站在世界之巅，在 AI 淘金热中靠卖铲子赚取了数千亿美元的利润——而这反过来又把内存和存储的价格推上了天。

坏消息是，这让这些 RTX Spark 笔记本非常昂贵，尤其是如果你想要足够的内存和 GPU 核心来实现它们所宣称的一切功能。售价 2,600 美元的 Surface Laptop Ultra 实际上起步配置是阉割版的英伟达 N1X，配备 18 个 CPU 核心、5,120 个 GPU 核心和 24GB 内存；想要完整的 20 个 CPU 核心和 6,144 个 GPU 核心，你得付 3,700 美元；如果想要 128GB 统一内存来容纳更大的本地 AI 模型，最高要花 5,900 美元。

好消息是，包括微软在内的 Windows PC 厂商，如今既然有底气要这么高的价，似乎也更有胆量去追求 MacBook Pro 级别的品质了。而等到我们普通人也能买得起英伟达机器的时候——英伟达表示 Spark 是一个产品家族，正在开发成本更低的版本——或许早期的成长阵痛也已经被解决了。

最好的消息是，英伟达正在构建的未来并不只属于英伟达。Qualcomm 帮助成就了今天的 Windows on Arm，而英伟达也应该会让明天的 Qualcomm 机器变得更好。

Arm 的涨潮托起了它的所有船。
