微软认为其新的 Copilot「超级应用」将像 Office 一样有影响力

The Verge · AI · 评分 7/10：微软 Copilot 超级应用整合 chat、编码与 agent，属 agent 工具链动态
原标题：Microsoft thinks its new Copilot ‘super app’ will be as influential as Office

要点

  • 微软正式发布全新 Copilot「超级应用」，整合聊天、编程与 agent 三大功能
  • 新应用设 Home、Code、Autopilot 三个标签页，Scout 更名为 Autopilot
  • Code 标签由 GitHub Copilot 技术驱动，可在沙箱内创建并托管内部应用

在上个月预告了其全新的 Copilot“超级应用”之后，微软今天正式揭开了它的面纱。重新设计的 Copilot 应用将聊天、编程和 agent 三项 AI 能力整合到同一个界面中。作为此次发布的一部分，微软还将今年早些时候在 Build 大会上推出的AI 个人助理 Scout 更名为 Autopilot。

这款全新的 Copilot 应用将设有 Home、Code 和 Autopilot 三个标签页，其中 Home 将 Copilot Chat 和 Cowork 整合在一起。它是 Copilot 用户的默认落地体验，微软还计划在其中加入 Today 功能，作为重要邮件、会议邀请、Teams 会话串等内容的个性化仪表盘。

“Home 是你找准方向的地方，让你脚踏实地、不断向前：查看近期活动、获取 Copilot 能提供哪些帮助的建议，并从上次中断的地方继续工作，”微软 AI at Work 首席营销官 Jared Spataro 解释道。

图片：Microsoft

Code 标签页是这款所谓“超级应用”中出人意料的补充，通常你不会把它与一款面向知识工作者的应用联系在一起。它让任何人都能创建应用、追踪器、仪表盘或自动化流程，并将成果作为云端托管的内部应用与同事分享。“Code 由与 GitHub Copilot 相同的底层技术驱动，在沙盒环境中运行，并可安全地托管在你的租户内，”Spataro 表示。

Autopilot 是 Copilot 体验中的新增成员，Spataro 将其描述为“数字队友”。它此前名为 Scout，最初以桌面应用形式提供，而 Autopilot 是与之对应的云端版本，能让个人 AI 助理在你睡觉时继续运行。与许多其他 AI agent 一样，Autopilot 拥有自己的云端计算机实例，可以执行诸如监控 Teams 频道、运行周期性工作任务或处理后续跟进等任务。

与其他一些 AI agent 的真正区别在于，微软将 Autopilot 打造成了企业级产品，以吸引依赖其 Office 和身份管理套件的企业。“Autopilot 存在于你的租户中，拥有自己的身份、记忆、计算机和工作区，并且构建在 Microsoft IQ 之上，因此它了解你的组织实际是如何运作的，”Spataro 说。“它会出现在人们已经工作的地方——Teams、Outlook、聊天、频道和文档——因此你可以像 @ 同事一样 @ 它，背后有权限、审计和治理作为支撑。”

图片：Microsoft

所有这些对企业安全与管控的关注，是微软再次向企业推销 Copilot 的重要一环。这一次的不同之处在于，企业为 Copilot 支付多少费用将取决于其员工在做什么。微软对这款新 Copilot 应用中的 Cowork、Code 和 Autopilot 部分采用按使用量计费的方式，因此任何长时间运行的 agent 能力或对 Astra、Fable 等模型的使用都将按使用量计费。

常规的 Copilot 许可证，即用户订阅许可证，将让你在 Chat 以及 Word、Excel、PowerPoint、Outlook 和 Teams 中使用 Copilot。微软采用自动模型选择器来为每项任务匹配模型，但 IT 管理员需要使用微软新的 FinOps for AI 来管理 AI 支出，并确保任何 agent 使用不会失控。

有了这款全新的 Copilot 应用，感觉微软终于为它的 AI 助手敲定了一套固定打法。自 Copilot 作为 Bing 内置聊天机器人问世以来，微软已经对它进行了多次重新设计，而这次最新的三标签页设计，是建立在上个月将两个独立的消费版和商用版 Copilot 应用合二为一的基础之上。这是一次迟来的改变，同时伴随的还有一些重大的 AI 领导层调整，正是这些调整首次帮助任命了一位统一的 Copilot 负责人。

新的 Home 和 Code 标签页将在“未来几周内”开始向微软的 Frontier 计划推送，该计划用于提前体验 AI 功能，而 Autopilot 将于本月晚些时候进入私密预览阶段。Code 也将在今年晚些时候面向 Microsoft 365 Premium 和 Pro 订阅用户开放预览。

平心而论，与 Claude 或 ChatGPT 相比，Copilot 在消费级市场算是失败了，但微软的核心商用客户正慢慢表现出兴趣。这款新的 Copilot 应用其实并不是为了与 Muse 之类的产品竞争而设计的，微软现在称它为“为工作而生的 AI”。微软 CEO 萨提亚·纳德拉也将 Copilot 称为一种新的操作系统。“我们正在把 Copilot 打造为一种全新的工作操作系统，它横跨每一种模型、每一种形态和每一项任务，”纳德拉在 X 上的一篇帖子中说道。

微软甚至将新的 Copilot 与当年 Office 对生产力的影响力相提并论。“正如 Office 定义了 PC 时代的工作方式，新的 Copilot 就是为定义 AI 时代的工作方式而打造的，”斯帕塔罗说道。

这很可能就是微软的目标，但 AI 时代的竞争远比 PC 时代激烈得多。微软无疑已经落后于 Google、OpenAI、Anthropic，如今还有 Meta，而“为工作而生的 AI”是否足以帮助它迎头赶上，将会很有意思。
