OpenAI Codex 0.157.0

OpenAI Codex Releases · 评分 7/10：Codex正式版新增GPT-6模型支持与多项交互功能
原标题：0.157.0

要点

  • Codex 0.157.0 新增 GPT-6 Sol 和 Luna 模型，支持 Amazon Bedrock
  • 默认启用全屏 transcript 和后台服务自动启动
  • 文件上传超时从 60 秒延长至 5 分钟，并增加失败重试

新功能

  • 新增 GPT-6 Sol 和 Luna，包括对 Amazon Bedrock 的支持以及针对旧模型的迁移提示。（#47332，#47347）
  • 默认启用全屏转录，并新增 Shift 点击以扩展文本选择范围。（#47178，#47414）
  • 为符合条件的交互式会话启用后台服务器自动启动，并在服务器设置不兼容时提供恢复选项。（#47179，#47318）
  • 新增 f 快捷键，可在其他应用中打开分叉对话，同时保留草稿和排队的 prompt。（#47185）
  • 使 /import 在远程会话和本地后台服务器会话中可用。（#47317）
  • 改进终端渲染，支持 Unicode 项目符号、复选框、对齐的公式和优化符号。（#47191，#47322）

Bug 修复

  • 切换线程时保留正在进行的语音对话。（#47381）
  • 在轮次结束时将未发送的问题答案恢复到编辑器中，且不干扰正在进行的会话历史搜索。（#47422，#47423）
  • 在自动屏幕模式下，遵循 tmux 鼠标设置，并恢复通过 SSH 使用 Terminal.app 时的原生回滚。（#47399，#47417）
  • 修复了实时连接和独立网页搜索（包括搜索重定向）的已配置代理路由。（#47101，#47142，#47204）
  • 为暂时性文件上传失败添加了重试机制，并将上传超时时间延长至五分钟。（#47122，#47393）
  • 在重定向以及持续的 HTTP 和 WebSocket 流量中强制执行网络限制，包括在策略变更撤销访问权限时取消连接。（#47389，#47407）
