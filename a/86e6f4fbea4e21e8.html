Brian Chesky 访谈：AI agent 需要自己的操作系统

TechCrunch · AI · 评分 6/10：关于 agent 原生 OS 与 Airbnb agent 化的观点
原标题：Brian Chesky interview: AI agents need their own operating system

要点

  • Airbnb本周随秋季更新上线AI搜索，CEO称聊天机器人不适合电商
  • Chesky认为未来界面介于聊天机器人与当前版本之间，需支持多人协作
  • Airbnb计划让应用更"agent友好"，未来或通过MCP实现agent互通

Airbnb 本周推出了其全新的 AI 驱动的搜索功能，作为秋季更新的一部分，这对一家在 AI 方面一直行动缓慢且谨慎的公司来说是一个重要的进步。联合创始人兼 CEO Brian Chesky 过去曾表示，仅靠聊天机器人的界面不适合旅行发现。随着更多 AI 功能即将登陆 Airbnb 应用，我通过 Zoom 与 Chesky 进行了交流，讨论了公司如何应对这一趋势、界面将走向何方、为什么消费者 AI 仍然行不通，以及语音将扮演什么角色。

Chesky 对聊天机器人的看法没有改变。他表示，聊天机器人不适合浏览或购物，因为它们一次只给你几个选项，而且你需要多轮交互才能得到结果。但他也不认为 Airbnb 当前的搜索版本是最终形态：其界面会随着时间的推移而演变。

“我认为，长期以来我一直相信聊天机器人不是电子商务的正确界面。我认为你今天看到的也不是电子商务、旅行或购物的终局。我认为会出现某种界面，你知道，我不想称之为中间点，而是介于聊天机器人和我们发布的第一版界面之间的某种东西，”他说。

Chesky 继续说道：“你知道，很多人希望某些事情……快速简便，比如‘帮我订一张机票，我不想看它。’而在 Airbnb 上，他们享受浏览产品。旅行研究表明，人们在规划和期待旅行时获得的乐趣实际上比旅行本身更多。所以，你不想剥夺那种灵感、浏览和梦想的图书馆体验。”

Chesky 看到了聊天机器人的第二个问题，即它们是为一个人构建的。他觉得它们不是协作界面，这对于人们经常与家人和朋友一起使用的产品来说很重要。在接下来的三到六个月里，公司的任务是探索能够实现“多人”AI 的界面，即几个人（例如一起规划旅行的团体）可以同时使用的 AI。

Airbnb 并不是唯一一家重新思考 AI 界面应该是什么样子的公司。随着 AI 工具的发展，新的界面也出现在应用中。像 Monogram 这样的初创公司，以及最近的 Wabi，正在试验“生成式”界面，即 AI 即时构建的屏幕，而不是设计师预先固定的屏幕。Chesky 认为，人们将看到确定性（预先设计和可预测）界面和生成式界面的混合。

我询问 Chesky，Airbnb 如何为消费者 AI agent 做准备，这些工具如 Instinct 和 Muse 可以代表个人执行任务。他说，agent 需要在 Airbnb 端有强大的软件基础设施，公司希望让自己对 agent 更友好。在他看来，它们可能是很好的潜在客户生成器。

“我不一定知道是否相信未来会有应用，但我不相信应用会成为通用简单 UI 的数据层，因为当你打开 iPhone 时，Airbnb 的应用设计与 DoorDash、Shopify 和 Amazon 不同是有原因的。我们的界面应该适应我们所做的实用性和功能。我们希望让我们的应用更具 agent 特性，并构建更多的用户界面控件，”他说。

“如果我有一个 agent，但我又想要真正出色的浏览功能，如果我想能像 Airbnb 那样给房东发消息，如果我想能进行比较，如果我想能验证自己的身份，如果我想能使用地图功能，如果我想接着能添加其他项目，然后如果我想留在平台内，那么要么 agent 必须进行交接，要么 agent 应用需要构建更多我认为更强大的软件开发工具包，以便把应用带给你，可以这么说。”

Chesky 认为，人们曾担心 AI 工具会把 Airbnb 这样的公司排除在客户关系之外，但他表示，聊天机器人已被证明擅长挖掘潜在客户。

这位 Airbnb CEO 还在为通过平台进行的 agent 对 agent 交互做规划。他解释说，平台内可能会有一些交互，另一些则与其他应用的 agent 进行。他的论点是，除非公司之间达成商业协议，否则应用并不总能互操作。另一方面，agent 就像“有面孔的应用”，当它们彼此交谈时，所有应用都能实现互操作。

“我认为 Airbnb 应用有一天会变成一个 agent，你知道，基本上就是探索标签页有一个 agent，我们的客服有一个 agent，我们正在另一个服务领域开发另一个 agent。最终可能会有一个宏观的 Airbnb agent。它很可能会通过 MCP（一种让 AI agent 与其他软件连接的标准）与其他 agent 互操作，”Chesky 指出。

Chesky 认为，更大的问题在于业界缺乏一个真正为 AI 构建的操作系统。目前人们正在为 iOS、macOS 和 Windows 构建 AI 应用，而这些并不是“AI 操作系统”。他认为，在理想情况下，AI 应该能在内核层面——操作系统的核心——运行，所有像 agent 这样的组件都能彼此交互。他说，目前这场竞赛的目标是成为“四分卫”，也就是用户处理一切事务时都要经过的主要 AI agent。

“那种模式（试图成为主要 agent）的问题在于，没有人在开发完整的操作系统软件开发工具包。我举个例子，”他继续说道。“ChatGPT 在去年年初试图做他们那个小小的应用商店。我告诉 Sam（Altman）：如果你想成为像 iPhone 那样的应用商店，你就需要有软件开发工具包和像 App Store 那样的操作系统。否则，我们的任何功能都不会存在。当然，它并没有很好地运作起来，”Chesky 说。

“我在 Muse 和 Instinct 上用过 Airbnb，”他接着说。“它运作得不太好。我的意思是，就连酒店都不太好用，但 Airbnb 更糟。所以我认为我们还没有攻克消费级 AI。要攻克消费级 AI，我们必须在更底层的基座上取得突破，我们需要让 agent 变成应用；所有应用都需要变成 agent；所有都必须互操作；所有都必须有丰富得多的用户界面。”

Chesky 认为硅谷存在两种误解：第一，界面将会消失，人们只会说话和打字；第二，软件将完全生成式。他的论点是，设计师能比消费者提示出更好的软件。

他还认为，只要 iPhone 仍占主导地位，且 Apple 和 Google 控制着主要平台，应用就很可能会继续是核心的固定存在。

“这真的取决于 Apple 或 Google，或者某个人，为我们构建一个新平台，才能真正实现从应用到 agent 的转变。否则，我们将会拥有内部带有 agent 的应用，而不是整个应用本身就是一个强大的、能与其他 agent 互操作的 agent，”他说。

在结束之前，我问了切斯基关于语音的看法。随着 Wispr Flow、Willow、Superwhisper 等应用、新一波笔记应用，以及 AI 工具内置的听写功能让人们越来越多地与设备对话，语音正在日益普及。他认为，人们最终用语音与计算机交流的次数会超过打字。他说，语音将在 Airbnb 的搜索和客户服务中发挥关键作用，公司计划今年秋天推出语音 agent 来帮助用户。

他还主动提到，公司通过使用 AI 来更快地交付功能，也获得了巨大收益。在个人层面，切斯基表示 AI 帮助他更快地获取信息，让他从大量会议中解放出来。

“我认为 AI 正在减少沟通层级。作为 CEO，我的工作之一就是获取信息。而我过去获取信息的方式就是开会。现在，我可以直接问我的 AI，不需要开那么多会了，”他说。
