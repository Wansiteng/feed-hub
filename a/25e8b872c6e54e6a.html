GPT-6 与面向所有人的智能 UI

评分 9/10：OpenAI 重要模型发布，全球上线，必看
原标题：GPT-6 and Intelligent UI for everyone

要点

  • OpenAI 向 ChatGPT 每周 12 亿用户推出 GPT-6 模型
  • GPT-6 引入 Intelligent UI，可生成图表、按钮、表单等交互界面
  • GPT-6 支持边思考边作答，网页搜索场景下响应快 44%

上个月，我们为付费用户推出了首批 GPT‑6 模型，今天，我们通过一款全新的 GPT‑6 模型，将这一代智能带给每周使用 ChatGPT 的超过 12 亿人。

ChatGPT 中的 GPT‑6 引入了 Intelligent UI，这是一项新能力，让 ChatGPT 能够通过完全可交互的用户界面快速作答，使日常回答更加直观，让复杂主题的学习更加轻松，并能即时创建工具来解决问题。

我们训练 GPT‑6 使用文本、视觉元素和交互元素来组织回答，并根据你的问题决定它们如何组合。借助 Intelligent UI，回答可以包含图形、可点击按钮、表单、图表，以及你可以在对话中直接使用的交互体验。

格式取决于你所问的内容。对比可能最适合并排展示。解释可能通过交互式图表更容易理解。而当简单的文字回答最有用时，ChatGPT 也可以直接给出。

ChatGPT 可以通过展示各部分如何组合，让计划更易于遵循。 周日烤肉的时间安排可以放在食谱旁边，公路旅行的停靠点可以显示在地图上，并附上值得绕道一游的备注。

视觉化和交互式解释让你可以探索某件事如何运作、更改输入看看会发生什么，或一步步解决一个问题。

你也可以让 ChatGPT 为手头的任务创建一个工具，比如用来探索储蓄如何增长的计算器、和朋友聚餐时用的账单分摊器，或者一个可以在对话中玩的游戏。

借助 Intelligent UI，我们让 GPT‑6 可以自由地为每个问题创建最有用的界面，同时在网页端和移动端保持快速且熟悉的体验。

我们构建了一个原生、可流式传输的组件库，以及一个在模型生成界面的同时对其进行处理的编译器。该组件库为每个回答提供熟悉的设计基础，同时给模型留出决定各部分如何组合的空间。编译器让界面可以在模型生成时逐步呈现，而无需等待整个回答完成。

我们扩展了训练方法，帮助模型在内容、布局、视觉和交互方面做出周全的决策。这包括评估它创建的界面是否清晰、有用和完整。GPT‑6 学会了使用组件库并做出良好的设计决策，包括如何清晰地组织信息、何时使用交互，以及何时简单的文字回答就足够了。

在改进模型的设计判断力和扩展其创作能力方面仍有工作要做，但 Intelligent UI 标志着人们与 ChatGPT 互动方式的重大转变。ChatGPT 不再把每个问题都塞进同一种对话格式，而是可以结合 UI、数据和操作，为人们探索、理解和互动信息创造全新的方式。

借助 GPT‑6，我们还让 ChatGPT 能够在继续思考的同时开始作答。

随着推理模型的引入，用户可以解决更难的问题，但必须等待模型完成思考后才能得到答案。现在，ChatGPT 可以将思考与作答交错进行。我们训练它考虑用户的等待时间，并利用其截至当时的知识和发现逐步组织答案。它学会了通过多个部分回答来构建答案，每个部分都添加有用的信息，没有不必要的填充，同时让完整答案像一次性写成的答案一样连贯且符合事实。

在对高价值日常 agentic 任务的内部评估中，GPT‑6 Extra High 能够以与 GPT‑5.6 Medium 相同的耗时开始作答，同时取得比 GPT‑5.6 Extra High 更好的总体得分。

对于需要网络搜索的问题，GPT‑6 Instant 平均比 GPT‑5.6 Instant 提前 44% 开始作答。

GPT‑6 还提升了需要网络搜索的答案质量。它能更好地判断何时需要查询，并更可靠地找到支持其答案的信息。在一项针对难题的内部评估中，GPT‑6 比 GPT‑5.6 更频繁地正确回应了用户问题的关键方面。

随着我们将更智能的 AI 带给更多人，我们致力于改进它识别现实世界风险的方式、回应的诚实程度，以及对人们所设限制的尊重程度。GPT‑6 在这些方面均取得进展，基于 Astra 的多项安全进步，更好地抵御绕过其安全训练的尝试、遵循防护措施，并相比 GPT‑5.6 Sol 更清楚地说明自己能做什么、不能做什么。我们根据现实世界使用中的经验教训更新了其安全训练，以加强对涉及网络攻击、生物威胁和暴力的高风险滥用的防护。在对抗性测试中，GPT‑6 对绕过其安全训练的尝试表现出更强的抵抗力，尤其是跨多轮演变的攻击。GPT‑6 还经过训练，能在更高风险场景中安全回应，同时避免对无害请求的不必要拒绝。这包括利用对话历史和相关上下文来识别单条 prompt 中可能不明显的风险。

我们在整个训练过程中进行了对齐评估，考察诚实性以及对安全限制的回应。GPT‑6 更善于识别并说明自身能力的局限，包括在缺乏回答问题所需信息或工具时。有关结果和我们审查的更多细节，请参阅系统卡⁠（在新窗口中打开）。

搭载 Intelligent UI 的 GPT‑6 今天起在 Chat 标签页面向 ChatGPT Plus、Pro、Business 和 Enterprise 层级全球逐步推出。从明天开始，推广范围将扩展至 Free 和 Go 层级。Enterprise 的可用性取决于工作场所管理员设置。

ChatGPT 中的 GPT‑6 在 Plus、Pro、Business 和 Enterprise 层级由 GPT‑6 Sol 驱动，在 Free 和 Go 层级由 GPT‑6 Luna 驱动。两者都针对日常对话进行了调优。

本次更新适用于 ChatGPT 中的 Chat 体验。驱动 Work 和 Codex 的模型不会随本次发布而改变。

我们的使命是将通用人工智能的益处安全地带给全人类。GPT‑6 将我们在智能方面的最新进展带给每周使用 ChatGPT 的超过 12 亿人。

Intelligent UI 是迈向这样一种 ChatGPT 的一步：它能够围绕你试图完成的事情来塑造界面。

随着时间的推移，我们希望 ChatGPT 能创造更多人们日常任务所需的界面。你应当能够描述自己想要完成的事情，并基于此获得量身打造的体验。

几十年来，人们不得不学习如何使用软件，在围绕特定任务设计的固定界面中摸索。我们相信未来会有所不同。不再是人们去适应软件，而是软件将适应人。
