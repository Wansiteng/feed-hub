Ollama v0.34.3

Ollama Releases · 评分 6/10：新增 thinking 控制查询与 Apple Silicon 视觉模型支持，有实质功能
原标题：v0.34.3

要点

  • Ollama v0.34.3 发布，GET /api/show 新增模型 thinking 控制项与默认值
  • Nemotron H 视觉模型现可在 Apple Silicon 上通过 MLX 运行
  • macOS 应用激活时不再重新打开已关闭的窗口，并修复 HuggingFace 模型拉取问题

变更内容

GET /api/show 现在会返回每个模型的思考控制项及默认值：

可在 CLI 中使用：

ollama show gemma4

    thinking
        levels     false, true
        default    true

可在 API 中使用：

curl http://localhost:11434/api/show -d '{"model": "glm-5.3-flash:cloud"}'
{
  "thinking": {
    "values": ["low", "high", "max"],
    "default": "max"
  }
}

云端模型也可直接在 ollama.com 上使用。

  • Nemotron H 视觉模型现已在 Apple Silicon 上通过 MLX 获得支持
  • Ollama 的 macOS 应用在激活时不再重新打开你已关闭的窗口
  • 修复了从 HuggingFace 拉取模型的问题
