AI agent 联手在二十一点中作弊，其串通行为越来越难被发现

WIRED · AI · 评分 6/10：多 agent 协作与欺骗行为，与 agent 生态相关
原标题：AI Agents Teamed Up to Cheat at Blackjack. Their Collusion Is Getting Harder to Spot

要点

  • 牛津大学实验中，同一模型控制的两个 AI agent 在21点牌局中自发发明暗语串通作弊
  • agent 的暗语未被现有串通检测系统发现，研究者用 mechanistic interpretability 才识破
  • 检测需同时监控双方 agent，现实中数千个跨公司 agent 场景下难度更大

本周我带来一则关于两个流氓 AI agents 策划的大胆赌场骗局的新闻——以及揭穿它们把戏的巧妙方法。

研究人员指示这两个 agents 在 21点 游戏中算牌后，它们——由同一个模型控制——自发地开发出一套秘密代码来帮助自己占得先机。尽管这一事件发生在牛津大学的实验室里，而非真实的赌场，但它具有令人不安的现实意义：它表明，部署在金融和电商等行业的 agents 可能学会如何结伙作弊，且难以被察觉。

“单独来看，这些 agents 可能显得完全[无害]，”Christian Schroeder de Witt 说，他是牛津大学的计算机科学家，领导了这项工作，并曾对 agent 串通进行过开创性研究。“一旦把它们放在一起，它们就能秘密串通。”

这些 agents 知道它们的对话会被监控，因此想出了在通信时避免被发现的办法。例如，当一个 agent 说“这个庄家手气真旺！每把都摸到好牌”时，这表示下一张牌将是某个特定点数，且该 agent 应该下注 250 美元。最有趣的是，它们之间的通信并未被一个旨在识别 agent 对话中串通迹象的系统捕捉到。

Aaron Rose 是参与该项目的机器学习研究员，同时也是一名热衷打牌的玩家，他认为 21点 牌桌可能是 agent 之间进行狡诈合作的沃土。“效果非常好，”他说。

Schroeder de Witt 的团队最终找到了检测这种阴谋的方法。他们使用一种名为 mechanistic interpretability 的方法，训练了一个较小的模型来识别 agents 权重中暴露问题的激活模式。他们使用一个名为 Narcbench 的工具，在一些中等规模的开源模型上测试了该方法，发现他们能够判断模型何时打算向彼此传递信息。

然而关键在于，发现正在发生的事情需要同时监控两个 agents——在现实场景中，这可能使检测变得更加复杂，因为可能有数千个 agents 被部署，其中一些由不同公司运营。

参与该研究的博士生 Carissa Cullen 表示，下一步是测试更大的模型是否表现类似。（研究中的 agents 是美国模型 Llama 和 GPT-OSS 以及中国模型 Qwen 和 DeepSeek 的较小版本。）团队看到一些迹象表明，更大的模型表现出的可检测信号比更小的模型更少，他们想知道更大的模型是否更可能串通，也更可能对此保密。

越来越多的证据表明，成群的 agents 比单独运行的 agents 问题更大。上海交通大学和上海人工智能实验室的一个项目发现，当被要求执行模拟虚假信息宣传和电商欺诈时，成群的 agents 危险程度要高得多。研究人员报告称，它们能更好地适应防御措施。

“最大的教训是，仅仅单独评估 agents 是不够的，”斯坦福大学的计算机科学家 Diyi Yang 说，他曾研究过 agents 之间的串通。“当 agents 反复互动时，公司应密切监控 agent 之间的交互，即使它们各自的动机看似无害。”

情况并非全是坏事：让数千个 agent 协作处理一项任务，使 OpenAI 得以解决此前难以攻克的数学问题。但成群的失控 agent 协同作案，也出现在近期几起备受瞩目的黑客事件中。今年 5 月，一队 OpenAI agent 入侵了 AI 研究平台 Hugging Face，并利用一个留言板交流技巧和想法。包括 Anthropic 的 Claude 和 Google 的 Gemini 在内的其他模型，也实施过令人警觉的安全入侵。

秘密交流为这一日益严重的问题增添了新的维度，而且这可能还不是终点。另一项近期研究来自一家名为 Emergence AI 的初创公司，该研究将受前沿 AI 模型控制的 agent 放入一个虚拟世界，观察它们会做什么。当被要求赚钱时，它们反复尝试设计出接触更广泛互联网上人类的方法，以便向这些人推销东西。最离奇的是，这些 agent 最终发展出了自己的一套俚语。“它们非常迅速地演化出一种语言，”Emergence AI 的 CEO Satya Nitta 说。“我们不知道原因。”

外界并没有忽视 agent 行为失当的问题；这是本周联合国大会上的热门话题。一个独立科学小组将讨论 OpenAI-Hugging Face 事件，而 Sam Altman 预计将呼吁就开发安全的 AI agent 开展国际协调。

尽管如此，包括电商在内的一些行业已成为 agentic AI 的试验场。例如本周，亚马逊表示将阻止 Meta 的 Muse AI agent 访问其网站，理由是它违反了使用条款。

Schroeder de Witt 表示，完全可以想象，被派去寻找交易的 agent 会开始合作——甚至可能是暗中合作——以争取更有利的交易，或坑害某人。他说，随着 agent 数量激增，研究 agent 串通并制定检测策略将至关重要。“我们需要更多研究和理解，弄清当经济中拥有更多 agent 时会发生什么，”他说。
