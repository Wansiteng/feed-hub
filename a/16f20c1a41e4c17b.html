Intel 将在 Xeon Diamond Rapids 后淘汰 SGX，转向 TDX

Tom's Hardware · 评分 6/10：芯片安全技术路线重大调整，涉及 agentic AI 需求
原标题：Intel to phase out SGX after Xeon Diamond Rapids in favor of TDX

要点

  • Intel 宣布 Xeon Diamond Rapids 将是最后一代支持 SGX 的处理器，之后转向 TDX。
  • Intel 将继续为 SGX 平台提供安全更新和支持至 2030 年代初。
  • TDX 隔离整个虚拟机，无需修改应用，更适合云服务商和 agentic AI 工作负载。

在将其 Software Guard Extensions（SGX）技术引入主流服务器平台仅五年后，Intel 于周五宣布计划在即将推出的 Xeon“Diamond Rapids”CPU 之后停止对该技术的支持，并将机密计算方面的努力集中到 Trust Domain Extensions（TDX）上。该公司将继续为现有的支持 SGX 的平台提供支持直至 2030 年代初，但与此同时将扩展 TDX 能力，以满足 云计算、企业工作负载和 agentic AI 应用不断涌现的需求。

毫无疑问，数据主权要求正成为一个日益重要的因素，因为各组织希望保护敏感信息免遭未经授权的访问，即便这些信息是在第三方运营的基础设施上处理的。尽管 Intel SGX 和 TDX 都旨在保护处理过程中的敏感信息，但二者采用的方法存在本质差异。

SGX 在应用内提供受硬件保护的 enclave，将选定的代码和数据与其他软件（包括操作系统和 hypervisor）隔离。相比之下，TDX 将整个虚拟机与底层宿主环境（包括 hypervisor 和其他虚拟机）隔离。SGX 要求开发者设计或修改应用以使用受保护的 enclave，而 TDX 可以在机密虚拟机内保护现有工作负载，无需对单个应用进行大量改动，这使得 TDX 对运营大量虚拟机的云服务提供商尤其具有吸引力。

尽管多年来 SGX 和 TDX 都面临大量安全漏洞，包括侧信道攻击、权限提升缺陷以及针对其证明机制的攻击，但 Intel 并未将安全方面的顾虑列为决定停止 SGX 的原因。

Intel 逐步淘汰 SGX 的决定反映出业界更倾向于虚拟机级别的隔离，而非针对特定应用的 enclave。据 Intel 称，TDX 提供了机密计算广泛普及所需的可扩展性、部署便捷性和运营模式。尽管 SGX 曾在数据中心实现机密计算，并持续服务于注重安全的客户，但 Intel 认为未来需求将更青睐 TDX。因此，Diamond Rapids 将是最后一款支持 SGX 的 Xeon 世代，这为客户提供了数年时间来验证基于 TDX 的替代方案并迁移现有应用。Intel 将继续为支持 SGX 的平台提供安全更新和支持直至 2030 年代初，因此其客户将有充足时间为新部署采用 TDX。

与此同时，Intel 计划通过额外的安全技术扩展 TDX 能力。这些技术包括旨在实现可信 I/O 的 Intel TDX Connect，以及后量子密码学和增强的证明机制。可信 I/O 对于与外部设备通信的工作负载尤为重要，因为虚拟机内部计算的保护并不一定延伸到虚拟机与加速器或其他外设之间传输的数据（例如 CXL 扩展器，不过 Intel 并未明确说明这一点）。改进的证明机制将帮助各组织验证受保护环境的完整性，而后量子密码学将有助于应对未来的安全威胁。与此同时，Intel 尚未披露这些增强功能的具体可用日期。

Intel 机密计算战略背后的一个重要推动因素，似乎是 agentic AI 的加速普及。与传统应用不同，自主 agent 可能会访问敏感的企业信息、跨多个系统执行操作，并与其他 agent 交互。Intel 预计许多此类工作负载将运行在 CPU 上，而在这方面，TDX 可能为 agentic AI 应用带来实际优势。与 SGX 不同，TDX 无需大量软件修改即可保护整个 agent 执行环境，并允许多个 agent 在共享基础设施上各自独立的、硬件隔离的 VM 中运行。对于 GPU 加速的 AI 工作负载，Intel 与 Nvidia 合作，协调 CPU 和 GPU 上的机密计算技术，将保护扩展到整个处理流程中的敏感数据和 AI 模型（这显然比Intel 为 Nvidia 开发定制 Xeon CPU的范围更广）。

Intel TDX 已可通过主要云服务提供商使用，包括阿里云、Google Cloud、IBM Cloud、Microsoft Azure 和火山云。与此同时，Red Hat、Canonical 和 VMware 正在为其软件平台添加 TDX 支持，以推动其在私有云和企业环境中的采用。
