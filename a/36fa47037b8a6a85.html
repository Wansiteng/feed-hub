Muse 看起来很像 OpenClaw

The Verge · AI · 评分 7/10：消费级 AI agent 动态与架构对比，值得关注
原标题：Muse sure looks a lot like OpenClaw

要点

  • Meta 的 AI agent Muse 上线后登顶 App Store，美国日活约 60 万
  • Muse 与 OpenClaw 核心文件名和人格文档高度相似，被指直接套壳
  • Meta 高管承认 Muse 产品上深受 OpenClaw 启发，但称从零自研

我们似乎正在进入一个 AI agent 复兴时代。Meta 面向消费者的新 AI agent Muse 发布后不久便登上 App Store 排行榜榜首，据 Apptopia 估计，其在美国拥有 60 万日活跃用户。而 AI agent 平台 Instinct——其同名创始人的公司正以 25 亿美元估值融资——也一直在科技行业广为流传。不过，在底层，它们与开创这一切的平台 OpenClaw 存在一些明显的相似之处。

过去一周左右，一些社交媒体用户声称认为Muse 是直接基于 OpenClaw 构建的。这两个平台对核心文件（SOUL.md、memory、tools 等）使用相同的命名，并且在规范人格、语气等的文档中有大量相似的语句（“Be genuinely helpful, not performatively helpful”）。它们的设计也很相似。一位 Reddit 用户认为“Muse 只是一个构建在”OpenClaw“之上的包装应用”——并声称它可能也带有该平台重大的安全风险。“只有非技术人士才会为这种炒作买单。”

Meta 否认了这些说法。Meta 超级智能实验室产品负责人 Nat Friedman 在 X 上写道，Meta 是“从零开始”构建 Muse 的。不过，他确实承认 Muse“作为一个产品深受”OpenClaw“启发”。他说，在 1 月首次使用 OpenClaw 后，他为 Meta 的团队购买了数百台 Mac Mini。而在 Muse 上，他的目标是构建一个类似的平台，“我们可以让它安全可靠、易于使用，并扩展到数十亿人。”至于为何沿用了 OpenClaw 的文件名和语句，Friedman 表示，团队认为 OpenClaw 创始人 Peter Steinberger 把这些东西做得“完全正确”。

Instinct 看起来则没有那么直接的衍生关系。但就像 OpenClaw 当时具有革命性的消息功能一样，它允许用户直接通过消息工具与自己的 AI agent 沟通，人们也一直用它来处理那些让 OpenClaw 获得关注的同类日常、个人助理式用例。一位 Instinct 用户在 X 上盛赞称，这个 AI agent 为一次网络内就诊填写了文书、取消了订阅、组织了一场单身派对、为一次度假预订了活动、预约了 DMV、支付了一笔未结的通行费账单等等。另一位用户表示，他们的 Instinct agent 处理了他们在加拿大一家酒店遗失物品的找回事宜。

即使这两个平台都是从零开始构建的，它们对 OpenClaw 的亏欠也显而易见。

OpenClaw 并没有发明 AI agent 这个概念，但仅仅 10 个月，它就把 agent 从概念验证变成了真正实用的东西。它由一个人利用周末时间拼凑而成，运行在用户的个人电脑上，却以人们与他人交谈的方式与用户对话：在 WhatsApp、Telegram、Slack、Teams 或 Discord 等消息平台上。大约一周内，它就吸引了 200 万访客和 GitHub 上 10 万颗星，促使人们购买 Mac Mini 来 24 小时运行自己的 agent，启发有人为 AI agent 打造了一个社交媒体网络供它们“聊天”，还引发了 OpenClaw 用户在全球范围内的一系列线下聚会。

各大 AI 公司早已在 agentic AI 上大举押注，但它们的产品没有一个像 OpenClaw 那样取得突破，科技巨头也注意到了。2 月，OpenAI 聘请 Steinberger 为公司开发 agent。5 月，Google 在年度活动上公布了其消费级 AI agent 布局。6 月，Apple 决定全力投入 agent。8 月，Instinct 在私测阶段迅速增长，并融资数亿美元。9 月，Meta 推出了 Muse。可以说，OpenClaw 至少部分启发了它们所有人。

真正的问题不在于 Muse 这类产品是否抄袭了 OpenClaw，而在于它们是否改进了它。正如 Friedman 所指出的，OpenClaw 为数不多的明显问题之一就是安全性。该平台上最热门的 skill 之一包含恶意软件，而根据一位研究者的分析（该 Reddit 帖子后来被删除），OpenClaw 的 skill 仓库中有 15% 包含“恶意指令”，用于秘密访问用户数据或执行其他可疑任务。相比之下，扎克伯格写道，Muse 是“从底层开始就为隐私和安全而构建”的，用户数据和凭据存储在 Muse Secure VM 中，这是一台“带有浏览器、CPU、内存和存储的隔离 Linux 计算机”。

然而就目前而言，Muse 在安全方面的改进可能并没有它宣称的那么大。尽管用户数据与其他用户隔离，Meta 仍然可以访问它。该公司表示，计划在今年晚些时候推出一种方式，“以加密且可验证的方式阻止 Meta 访问你 VM 中的数据”。Muse 还默认允许 Meta 使用用户数据训练和改进其模型，不过用户可以退出。而最糟糕的或许是，本周一位研究者在 X 上标记的一个零日漏洞，让任何人都能通过简单攻击劫持该 agent，取得完全控制权。至于 Instinct，它因服务条款过于宽泛而受到抨击，尽管该公司似乎此后已对其进行了调整。

Meta 和 Instinct 最重要的演进，实际上只是让 AI agent 变得更加普及易用。有些人觉得 Muse 有用，原因之一是它能够集成到 Meta 的系统中，即便他们并不愿意把所有数据都交给这家公司。而 Instinct 允许用户通过 Apple 的默认消息应用与自己的 AI agent 聊天——这大大扩展了愿意尝试它的用户群体。虽然你可以在专用的本地设备上使用这两者——这样做也有潜在的安全好处——但这并非默认选项，同样也扩大了愿意尝试它们的人数。至少就目前而言，它们比Google 的 Spark 等竞品更便宜，而且尽管 Instinct 仍处于 beta 阶段，Muse 的一键下载已经克服了使用 OpenClaw 时的大量障碍。

今年 3 月，The Verge 曾写道，OpenClaw 用户社区将这款开源 AI agent 视为一场“草根运动和高尚追求，为人们提供了一个逃离由少数几家领先 AI 公司中一小撮人掌控的行业的出口。”如今，那些领先的 AI 公司正在发起反击。
