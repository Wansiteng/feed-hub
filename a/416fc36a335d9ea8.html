Dukosi 开放 DK-NFLNK 送样：电池 AFE 与 BMS 间的非接触式连接

Charged EVs · 评分 7/10：BMS 相关新技术，与读者本职工作直接相关
原标题：Dukosi opens sampling of DK-NFLNK, a contactless link between battery AFEs and the BMS

要点

  • Dukosi 的 DK-NFLNK 无接触通信方案开始向关键客户送样
  • 方案由 DK8503 Node 和 DK8203 System Hub 两颗芯片组成，采用单总线天线
  • DK-NFLNK 与 AFE 无关，无需改动电池架构，可用于 EV、储能和 AI 数据中心

Dukosi 已将其 DK-NFLNK 非接触式通信解决方案开放给主要客户进行送样。该方案专为基于传统多通道模拟前端（AFE）设计的电池而打造，Dukosi 表示 DK-NFLNK 通过使用单一总线天线，消除了传统的线缆和连接器。

该解决方案由两颗芯片组成，即 DK8503 Node 和 DK8203 System Hub，外加 Dukosi API 以及基于该公司 C-SynQ 的专有近场协议。每个 DK8503 Node 通过标准 SPI 接口连接到一个 AFE，产品页面列明每个 AFE 对应一个 Node。DK-NFLNK 将来自 AFE 的模块级同步测量数据提供给 BMS 主机，并通过总线天线和 DK8203 System Hub 在每个 AFE 之间传递数据，System Hub 则通过 SPI 连接到主机。该公司表示，该非接触式网络采用星型拓扑结构，并提供固有的电气隔离。

Dukosi 表示，同一个 BMS 主机处理器和 System Hub 可以在多种电池包设计中重复使用，并且通用的 DK-NFLNK 库和 API 支持所有配置，从而最大限度地减少软件开发与维护工作。

据该公司称，近场实现方式最大限度地降低了射频功率水平，并简化了机械集成。

DK-NFLNK 不依赖于特定 AFE，且无需改变电池架构，为设计人员提供了从有线或远场无线 BMS 设计升级的路径。

据 Dukosi 称，DK8503 和 DK8203 已通过 AEC-Q100 认证，并设计为符合 ASIL C 标准。

预期用途包括电动汽车、工业和船舶应用、机器人技术，以及用于公用事业和电网规模项目的电池储能系统（BESS）、电信基础设施和 AI 数据中心。

评估套件包括一块 Node 板、一个 System Hub 单元、一个可选的分压电阻板以及 USB、SPI、总线天线和同轴电缆。它还附带基于 Windows 的图形用户界面（GUI）、PCB 设计指南以及 DK-NFLNK 和 Dukosi 软件的用户指南。Dukosi 表示，该套件支持在一系列 BMS 主机处理器和 AFE 器件上进行技术评估和初步概念验证开发。

Charged 曾在 与 A123 Systems 和 Nuvation Energy 合作的 BESS 概念验证中报道过该公司的电芯上芯片监测系统。

“DK-NFLNK 和 Dukosi 电芯监测系统（DKCMS）共享一个通用的通信基础 C-SynQ，为电池设计人员提供了一条轻松的迁移路径，可转向完全支持 DKCMS 的 Smart Cell 电池设计，”Dukosi 总裁 Joseph Notaro 表示。
