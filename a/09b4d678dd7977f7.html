llm 0.36

评分 6/10：LLM 工具新增模型支持与对话能力标记，常规更新

要点

  • llm 0.36 新增 gpt-6-sol 和 gpt-6-luna 两个 OpenAI 模型
  • 模型插件可声明 supports_conversation = False，仅支持单轮 prompt
  • llm logs 的 Markdown 输出中推理轨迹现用 details 标签包裹

发布： llm 0.36

  • 新增 OpenAI 模型：gpt-6-sol 对应 GPT-6 Sol，gpt-6-luna 对应 GPT-6 Luna。#1702
  • 模型插件现在可以为仅接受单轮 prompt 的模型声明 supports_conversation = False。当这些模型收到 assistant 或 tool 历史记录时，LLM 会抛出 llm.ConversationNotSupported，而 llm chat 会在启动会话前拒绝它们。参见 不支持对话的模型。首个使用该功能的插件是 llm-typesafe。#1692
  • llm logs 的 Markdown 输出中的推理轨迹现在被包裹在 <details><summary> 标签中。#1701

此外还有 来自五位新贡献者的 bug 修复。
