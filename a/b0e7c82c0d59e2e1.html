将 AI agent 连接到企业知识

MIT Technology Review · 评分 6/10：MIT 长文谈 agent 与企业知识接入，与 agent 工具链相关
原标题：Connecting AI agents to enterprise knowledge

要点

  • 调查显示企业平均仅34%的agentic AI项目能进入生产环境
  • 生产领先者61%的agentic项目能超越试点，其语义知识能力更强
  • %的企业将数据碎片化视为扩展agent知识访问的最大挑战

尽管 AI 系统不断积累和分析大量数据，企业 AI agent 却常常面临一个奇怪的短板：缺乏知识。知识不仅仅是数据，更是理解数据在具体组织情境中的含义。AI agent 需要这种理解来推理情况、做出决策，并最终采取行动。没有足够的知识，agent 容易做出有缺陷且不可靠的决策。

我们的研究发现，知识缺乏是 agentic AI 用例无法投入生产的主要原因。竞争压力使得解决这一问题变得紧迫。组织需要部署和扩展更多 agentic 项目，以获取 AI 承诺的效率提升。如果做不到，就可能浪费已投入这些项目的资金，并将优势让给那些已经更有效利用 agent 的竞争对手。

下载报告

本报告基于对 300 名数据、AI 及其他技术高管的调查，目的有三。首先，它旨在评估组织的 agentic 知识能力（即其为 AI agent 提供对所摄取数据的完整情境理解的能力），涵盖语义知识、情景记忆和程序性知识。

其次，报告探讨了组织在改善知识获取以及最终将更多 agent 用例投入生产方面面临的挑战。第三，它探索了组织为克服这些挑战所采取的措施。

主要发现包括以下内容：

数据和知识薄弱持续阻碍 AI agent 进展。平均而言，组织只有约三分之一（34%）的 agentic AI 项目投入生产。即使是高科技公司也面临这一困境。遗留数据系统、安全与隐私问题，以及知识和情境的缺乏是关键失败点。

强大的知识能力与 agent 成功相关。一小部分生产领先者（其平均 61% 的 agentic 项目通过试点阶段的组织）拥有比其余组织更强的知识能力，尤其是在语义方面。这一优势与其更高的生产率密切相关。

碎片化数据极大复杂化了知识获取。数据碎片化（系统间数据共享不足）最常被列为扩大 agent 知识获取的首要挑战（55% 提及）。相比之下，生产领先者更可能将安全与隐私问题视为主要关切（该群体中 72% 提及）。

大多数公司旨在加强数据与 agent 之间的联系。在能够带来更高质量 agent 决策的步骤中，高管们预计最大影响来自加强组织数据与其 AI agent 之间的结构基础。我们采访的专家认为知识层是实现这一目标的主要方式。

提升知识的投资重点从管道到知识图谱不等。为扩大 agent 对知识的获取，组织将优先投资于检索技术，如摄取管道、AI-ready APIs 和 retrieval-augmented generation (RAG)；AI 评估 agent；以及知识图谱。
