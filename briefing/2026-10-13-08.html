1. Meta 发布首个前沿模型 Muse Wonder 系列

Meta 旗下 Superintelligence Lab 发布 Muse Wonder 和 Muse Wonder Full 两款模型，为其首个前沿模型。据内部测试，两者 benchmark 得分与 Fable 5.1、GPT-6 Astra 相当，擅长编程等复杂任务。Wonder 通过 Meta Model API 提供，每百万 input token 收费 4 美元、output token 收费 20 美元；Wonder Full 仅面向 Muse Code 订阅用户。两款模型将用于驱动 Muse agent。

2. 微软发布第三代自研 AI 芯片 Maia 300

微软发布第三代自研 AI 芯片 Maia 300，将作为其产品和服务的“主要 AI 推理系统”，2027 年起投产并扩展至多吉瓦部署。微软云业务负责人 Scott Guthrie 称，Maia 300 每兆瓦 token 量比主流 GPU 系统高 40%，96 加速器配置下机架级 token 吞吐量达 Maia 200 的 7 倍，将减少对英伟达和 AMD 芯片的依赖。

3. 开发者用 AI agent 重建《现代战争 2》源代码

开发者 Maurice Heumann 用 AI agent 反编译《使命召唤：现代战争 2》（2009），耗时三个月、消耗超 5000 亿 token，重建 C++ 源代码。目前游戏 99% 的函数已还原，83% 与原版一致，已可完整游玩。他估计项目共消耗 6000 亿至 7000 亿 token，若按 API 计费约需 20 万至 25 万美元。难点不在生成代码，而在验证其正确性。

5. 查尔姆斯理工研究可重构电池包延长电池寿命超20%

瑞典查尔姆斯理工大学与 PHINIA、Scania 合作，在《Nature Communications》发表研究，评估可重构电池包对电动车电池寿命和全生命周期成本的影响。传统电池包中，最弱电芯会拖累整体；可重构电池包通过开关和控制系统改变电芯连接，绕过问题电芯。模型显示，在电动卡车和长续航车等高压车型中，单独控制每个电芯可将电池寿命延长超 20%，但这是理论上限，实际更可能成组控制。
