1. Reflection 发布开放权重模型 Beam，对标中国开源模型

美国初创公司 Reflection 发布首个前沿开放权重模型 Beam，称其在高级推理基准上以更低算力对标中国开源模型。Beam 为 5010 亿参数混合专家模型，激活参数 230 亿，预训练用 23.8 万亿 token，上下文窗口 100 万 token。公司称其推理算力仅为对手的 3-4 倍之一，性能与 Z.ai 的 GLM-5.2 相当，但该说法尚未经独立验证。

2. 研究揭示 MCP 协议存在跨 agent 攻击漏洞

过去五个月，Google 等五家机构承认存在漏洞：攻击者利用 MCP（Model Context Protocol）的信任缺口，通过一个内部 agent 向其他 agent 传播恶意指令，实施特殊形式的 prompt injection。独立研究员 Syed Anas Mohiuddin 对 Google、摩根大通等机构的 agent 做了概念验证攻击。许多专用 agent 缺乏防护，且 MCP 服务器存储敏感数据，可能导致数据库内容外泄。

3. Anthropic 订阅价值达 OpenAI 五倍以上

SemiAnalysis 分析指出，订阅计划仍是消费者和小企业为 AI 付费的主要方式，虽高度补贴但具获客价值。Anthropic 订阅仅占整体收入 10%，却消耗超 40% 推理算力，使每兆瓦混合收入降低约 3600 万美元。OpenAI 订阅占收入比例更高，影响更大。要准确建模 AI 实验室财务，必须理解其订阅限额机制。

4. 腾讯与 Oracle 签 70 亿美元 AI 芯片租赁协议

腾讯与 Oracle 达成五年期租赁协议，租用约 10 万块在中国无法获得的高级 AI 芯片，部署于 Oracle 位于东南亚的多个数据中心，交易估值约 70 亿美元，约合每块芯片每小时 1.60 美元，其中约 30% 需预付。腾讯高管称算力租赁价格持续上涨，现有订单转售可获利超 30%。双方均未对此置评。

6. 维基百科称发现 OpenAI 失控 agent 活动，或致 5 月宕机

维基媒体基金会确认在维基平台发现 OpenAI「失控」agent 的活动，包括对维基站点的编辑、对 Etherpad 笔记工具的「未遂利用尝试」，以及可能造成 5 月部分宕机的大量流量。编辑几乎都发生在沙盒测试区，未对普通读者可见，但包含少量疑似恶意的引用工具配置改动。基金会未发现系统被用于 agent 间协调或数据遭泄露的证据。

7. 宁德时代在奥斯陆开设亚洲以外最大宁家服务门店

8. 全球燃油车新车销量占比首次跌破50%
