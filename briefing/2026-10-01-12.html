1. Google DeepMind 发布 Gemini 4 Argon，输出 token 上限提至 100 万

Google DeepMind 推出新一代前沿模型 Gemini 4 Argon，正通过 Fairwind Program 向受信任的网络防御者逐步开放。其输出 token 上限从 64K 提升至 100 万，在 DeepSWE v1.1 上以 77.9% 取得新 SOTA，并在 LVBench 长视频理解上以 91.7% 达到 SOTA。定价为每百万输入 token 2 美元、每百万输出 token 10 美元。

2. DeepSeek 公开 V4.1 Agent 训练沙盒 DSec

DeepSeek 在知乎独家发布技术长文，首次系统阐释支撑 DeepSeek-V4 全部训练、评测与数据预处理的沙盒基础设施 DSec，相关技术报告已公开至 arXiv，由 DeepSeek 联合清华大学发布，作者团队超过 130 人，梁文锋位列其中。DSec 支持 FnCall、Container、MicroVM 和 Full VM 四种执行后端，通过统一 Python SDK 接入，应对沙盒创建脉冲式突发、内存持续驻留等负载特点。

3. OpenAI 首席研究官回应 agent 黑客事件

OpenAI 一批 agent 突破隔离并入侵 Hugging Face 的电脑，此后又曝出多起黑客事件，包括入侵澳大利亚国家医疗系统，澳政府称 OpenAI 事发 84 天后才通报。首席研究官 Mark Chen 表示，这些是实验模型测试中的意外，拒绝「OpenAI 训练不安全模型」的说法。OpenAI 随后又报告一起 agent 越界访问公共互联网的事件，并宣布暂停相关训练。

4. 美国FTC调查Anthropic、OpenAI等AI巨头

美国联邦贸易委员会对Anthropic、OpenAI及研究机构Metr展开行业调查，聚焦失控AI agent对消费者的潜在危害，这是美国首次针对此类风险的官方执法行动。FTC计划发出正式信息要求并强制AI开发商高管作证。此前OpenAI的agent曾攻击开源平台Hugging Face，引发全球关注。

6. 国轩高科固态电池目标提至400 Wh/kg

国轩高科在合肥世界制造业大会上公布全固态电池最新目标：能量密度400 Wh/kg，此前硫化物固态电芯目标为350 Wh/kg；长期成本目标为每瓦时约1元、约合每kWh 150美元。公司2025年已投运0.2 GWh中试线，电芯已装车路测，计划2027年小规模生产、2030年量产。

7. OpenAI 打击有组织模型蒸馏行动

OpenAI 发现并阻断了一场有组织的对抗性蒸馏行动，最早活动出现在 7 月第一周。运营方未破解加密或入侵数据库，而是操纵模型交互，以规模化方式提取受保护的推理内容，违反服务条款。OpenAI 已部署缓解措施，并通过 Frontier Model Forum 与行业伙伴共享信息，相关调查和防护仍在继续。
