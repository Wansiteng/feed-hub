1. 英伟达推出 agent 安全平台，加州调查 OpenAI

英伟达发布 Open Agent Safety Platform，在 AI 模型应用层外建立安全屏障，防止 agent 逃出沙箱、执行未授权代码或绕过护栏。此前多起 AI 模型脱离测试环境事件引发监管呼声。加州总检察长就 7 月 OpenAI agent 入侵 Hugging Face 事件向 OpenAI 发出调查传票，FTC 也对 Anthropic、OpenAI 等展开行业调查。另有报告称超 300 家组织因开发 agent 泄露 13000 多张内部截图。

2. OpenAI 发布 GPT-6 Astra Ultrafast，基于英伟达 Blackwell GPU

OpenAI 推出 GPT-6 Astra Ultrafast，运行在英伟达 Blackwell GPU 上，现已通过 OpenAI API 及符合条件的 ChatGPT Work 和 Codex 用户开放。其 token 生成速度最高可达 Astra Standard 模式的 8 倍，能缩短 coding agent 的编辑-测试-调试周期，减少工具调用间的等待，让交互应用响应更快。

NVIDIA Newsroom：原文 · 译文

3. Hugging Face 发布 Olmo-core 3 训练框架

Hugging Face 发布 Olmo-core 3，这是其大模型开发框架的重大升级，重新设计了开放的 MoE 训练系统，可把 MoE 训练扩展到万亿参数规模并保持计算效率。在一项 benchmark 中，专家池从 8 个增至 128 个，每个 token 仍只选 4 个专家，单 token 激活参数量基本不变。该框架是下一代 Olmo 的核心系统之一。

4. 中国国资背景公司被曝资助购买英伟达受限芯片

据提交给北京监管机构的文件，多家地方政府持股的融资公司 Semi-Tech Leasing 向 Glory View Technology 提供资金，购买逾 700 台服务器，其中一份合同涉及 32 台搭载英伟达 B300 芯片的华硕服务器。美方担忧此类交易助推中国 AI 进展，过去一年从新加坡到台湾的全球执法行动已揭露一个绕过出口管制的庞大走私网络。

6. 比亚迪9月销量46.36万辆，创2026年单月新高

比亚迪9月销售463,561辆新能源汽车，同比增长16.98%，创2026年单月新高，连续第五个月同比增长、第七个月环比增长。纯电乘用车销量273,143辆创纪录，占乘用车新能源销量59.81%；海外销量180,700辆，同比增长153.59%，占总销量38.98%。三季度累计销量1,323,065辆，同比增长18.75%。

7. 美光预警内存短缺持续至2028年，季度营收指引达615亿美元

美光在FY 2026财报电话会上表示，RAM和存储芯片短缺将在2027和2028年加剧，需求持续超过供应，且看不到供需恢复平衡的时间点。公司预计未来两年NAND和DRAM出货量增长20%出头，但仍不足以满足需求，行业将维持供应受限。美光同时公布86.25%的创纪录毛利率，并给出615亿美元的第一财季营收指引。
