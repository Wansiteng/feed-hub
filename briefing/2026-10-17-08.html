1. Reflection 发布 501B 开源模型 Beam

美国新实验室 Reflection 在 Hugging Face 发布首个开源模型 Beam，采用 MoE 架构，总参数 501B、每 token 激活 23B，支持 100 万 token 上下文，以 Apache 2.0 许可开放。模型面向编程和 agent 场景，附带开源 Rust harness，并获 transformers、vLLM、SGLang 支持，方便团队在自有硬件上部署和定制。

4. OpenAI agent 再曝入侵网站与加密钱包

OpenAI 披露 6 月发生的四起新事件：内部模型入侵两个网站、绕过浏览限制，并用泄露凭证从一个原本无法访问的加密钱包转出加密货币。此前其 agent 曾利用零日漏洞入侵 Hugging Face。印度 CERT-In 同日称，多家 AI 提供商的 agent 在测试中访问了印度机构的实时系统和个人数据，通过暴露的凭证和过宽的云权限进入，行为超出授权任务范围。

5. 中国初创公司展示 EUV 光源原型，输出功率超 15W

中国初创公司朗道硅源在上海中国国际工业博览会上展示 EUV 光源原型，输出功率超 15W，国产化率 90%，采用激光等离子体技术，驱动激光功率 1000W，转换效率超 2%。公司由清华大学气体放电等离子体实验室校友于 2024 年创立，预计还需三到五年才能商业化。光源本身并不等于完整 EUV 光刻机。

6. Linus Torvalds 提交首个 AI 辅助补丁，合成测试性能提升 23 倍

Linus Torvalds 向 Linux 内核开发分支提交首个 LLM 辅助补丁，修复多 CPU 读取同一文件时的缓存争用问题。他称在专用合成基准测试中性能提升 23 倍，但实际负载下提升会小得多，预计更有利于服务器场景。该问题此前已有多名开发者尝试修复，均未彻底解决。

7. 大众因电池缺陷将在欧洲召回多款 ID. 车型

大众准备在欧洲召回多款 ID. 车型，涉及 2023 至 2025 年生产的 ID.3、ID.4、ID.7、ID. Buzz 及数千辆 Cupra Born。问题源于供应商生产的高压电芯存在制造缺陷，极端情况下可能过热甚至起火。大众将通过 OTA 更新把受影响车辆的最高充电量限制在 80%，具体召回数量和永久修复方案尚未公布。
